能把正整数逐位换算，并在给定位宽下求负数补码。

一串位怎样表示数

这一节要学会：能把正整数逐位换算，并在给定位宽下求负数补码。

十进制像每满十件换一箱，二进制像每满两件就向左换一箱。每一位的权重从右往左是 1、2、4、8……；位上的 1 表示取这个权重，0 表示不取。

13 = 8+4+1，所以二进制是 1101。反过来，1101₂ = 1×8+1×4+0×2+1。数值不变，只是写法改变。bit 是一个二进制位；课程常见环境按 1 Byte=8 bit 计算，遇到题设应以题设为准。

求负数补码必须先确定“几位”。下面限定 8 位补码：先写 +5 的 8 位形式，逐位取反再加 1 得到 -5。不要把符号位留下不变，那是把反码步骤和补码步骤混淆了。

查看完整过程，逐步核对

第 1 步

+5 的 8 位表示

位串：00000101

5=4+1，左侧补 0 到 8 位。

第 2 步

所有位取反

位串：11111010

0 变 1，1 变 0，此时还没完成补码。

第 3 步

最低位加 1

位串：11111011

得到 8 位补码 -5；最高位为 1 表示该位串按有符号补码解释时为负。

第 4 步

检查：00000101 + 11111011

低 8 位：00000000；进位：1

固定 8 位运算舍去第 9 位进位，验证两者相加为 0。

核对判断与理由

同一位串 11111011，解释成 8 位无符号数是多少？

  1. -5：-5 是有符号补码解释；本题明确为无符号。
  2. 251：对。128+64+32+16+8+2+1=251，解释规则影响数值。
  3. 123：123 忽略了最高位的 128。

正确判断：251

换个例子，自己试一次

先独立写出过程，再核对理由。遇到卡点可以回上一小节重走。

不用看演示，写出 6 的二进制，再求 8 位补码 -6。

卡住时看提示

先写满 8 位的 +6，再逐位取反。完成取反后还有最后一个步骤。

查看参考过程

6=4+2，写成 00000110；逐位取反得 11111001；加 1 得 11111010。位宽改变时表示长度也会改变。

核对判断与理由

8 位补码 -6 的位串是哪一个？

  1. 10000110：这是按符号加绝对值写法得到的原码，不是补码。
  2. 11111001：这是取反后的中间结果，还要加 1。
  3. 11111010：对。先固定 8 位，再取反加 1。

正确判断：11111010

一、存储单位：bit 与 Byte

计算机内部，数据以二进制形式存储和运算。最小单位是 bit（位），数据处理和存储容量的基本单位是 Byte（字节）。

换算说明
1 Byte = 8 bitbit 是最小单位
1 KB = 1024 B = 2¹⁰ B千字节
1 MB = 1024 KB = 2²⁰ B兆字节
1 GB = 1024 MB = 2³⁰ B吉字节
1 TB = 1024 GB = 2⁴⁰ B太字节

二、数制与转换

四个概念：数码、基数、位权、尾符。

进制数码基数尾符
二进制0~12B
八进制0~78O/Q
十进制0~910D
十六进制09、AF16H

转换口诀：

  • 非十进制 → 十进制：乘权求和。例：1101B = 1×2³+1×2²+0×2¹+1×2⁰ = 13D。
  • 十进制 → 非十进制：整数 除 N 取余，倒序输出；小数 乘 N 取整，正序输出。
  • 二进制 ↔ 八进制：每 3 位二进制 = 1 位八进制。
  • 二进制 ↔ 十六进制：每 4 位二进制 = 1 位十六进制。

相关信息

简答常考

175D = 10101111B = 257Q = AFH。要能写出除基取余的过程。

三、数据类型与原反补码

基本类型中先死记这四个：

类型字节位数范围
有符号 char（本课按 8 位二补码示例）18-128 ~ 127（-2⁷ ~ 2⁷-1）
unsigned char180 ~ 255（0 ~ 2⁸-1）
short216-2¹⁵ ~ 2¹⁵-1
int / long432-2³¹ ~ 2³¹-1
float432约 6 位有效数字
double864约 15 位有效数字

易错

易错点

实型常量如 3.14 默认按 double 处理，不是 float；写 3.14f 或 3.14F 才是 float。

原码、反码、补码

  • 最高位是符号位：0 正 1 负。
  • 无符号整数：二进制原样存储；有符号整数：补码存储；字符：ASCII存储。
  • 正数：原码 = 反码 = 补码。
  • 负数：反码 = 符号位不变，数值位取反；补码 = 反码 + 1。

例：-11（8 位）

码值
原码10001011
反码11110100
补码11110101

易错

特殊值

8 位有符号数中，-128 只有补码 10000000，没有原码和反码。

char 溢出回绕

以下按本课示例约定：char 为 8 位有符号二补码，超出可表示范围时按 ±256 回绕；实际 C 实现的 char 位宽与 signedness 可能不同。

  • char c = 128; → 输出 -128（128 - 256 = -128）
  • char c = -129; → 输出 127（-129 + 256 = 127）
  • unsigned char c = -1; → 输出 255（补码 11111111 按无符号读 = 2⁸-1）

四、常量与标识符

整型常量

进制特征合法例非法例
十进制普通数字100、-12—
八进制0 开头，数码 0~7066、023L66（缺 0）、08C2（含 8/C）
十六进制0x/0X 开头0x66、0xACFA8（缺前缀）、0x8CG（含 G）

实型常量

  • 十进制形式：3.14、.2、-9.，口诀是「点的一侧要有数」。
  • 指数形式 aEn：口诀是「e 前 e 后要有数，e 后必须是整数」。如 3.14e2、.7e-2 合法；7e0.0、6e 不合法。

字符与字符串

对比'a'"a"
引号单引号双引号
内存1 字节2 字节（含结束符 '\0'）
含义整型值（ASCII 码）地址值

常用转义字符速记：\n 换行、\t 制表、\\ 反斜杠、\' 与 \" 引号；\ddd 八进制、\xhh 十六进制。一个转义字符只占 1 字节，如 '\101' 就是 'A'。

易错

⚠️ 易错区分

'\101' 是字符型，内存占 1 字节；0101 是整型八进制常量，占 4 字节。两者不要混淆。

标识符

用户自定义标识符规则：

  1. 只能由字母、数字、下划线组成。
  2. 数字不能开头。
  3. 不能用关键字。
  4. 区分大小写（Int 合法，int 不合法）。

易错

高频陷阱

9_hool（数字开头）、he.llo（含点）、x￥yz（含￥）、int（关键字）、Text-0（含减号）均不合法。

符号常量与 const 常变量

#define PI 3.14：编译前把 PI 文本替换为 3.14，不占内存；它是预处理指令不是语句，末尾不加分号。const 常变量则占内存、有类型。

易错

宏定义陷阱

#define N 5 后写 N++ 不合法——N 是符号常量，不是变量。

五、先回忆，再自测

合上笔记默写：十进制转非十进制的口诀、175 的三种进制表示

整数部分「除 N 取余，倒序输出」；小数部分「乘 N 取整，正序输出」。175 = 10101111B = 257Q = AFH。

负数的反码、补码怎么求？-11 的 8 位原码、反码、补码各是什么？

反码：符号位不变，数值位取反；补码：反码 + 1。-11：原码 10001011、反码 11110100、补码 11110101。

用户标识符的三条硬规则是什么？判断 _buy_2、2_buy、Int、char 的合法性

字母/数字/下划线组成、数字不开头、不用关键字（区分大小写）。_buy_2 ✓、2_buy ✗（数字开头）、Int ✓、char ✗（关键字）。

六、测验（点击选项作答）

1. 十进制 175 对应的二进制、八进制、十六进制是

  • A. 10101111B、257Q、AFH
  • B. 10101111B、267Q、AFH
  • C. 10111111B、257Q、AFH
  • D. 10101111B、257Q、AEFH
点开核对答案

答案：A（10101111B、257Q、AFH） —— 175 除 2 取余得 10101111B；三位一组得 257Q；四位一组得 AFH。

2. 下列整型常量中，合法的是

  • A. 08C2
  • B. 0x8CG
  • C. 066
  • D. A8
点开核对答案

答案：C（066） —— 八进制以 0 开头且只能含 0~7；十六进制以 0x 开头且只能含 09/AF；A8 缺少 0x 前缀。

3. 下列实型常量中，不合法的是

  • A. .7e-2
  • B. 3.14e2
  • C. 7e0.0
  • D. -9.
点开核对答案

答案：C（7e0.0） —— 指数形式要求 e 后必须是整数，7e0.0 违反此规则；.7e-2、3.14e2、-9. 均合法。

4. 8 位有符号数 -11 的补码是

  • A. 10001011
  • B. 11110100
  • C. 11110101
  • D. 11110110
点开核对答案

答案：C（11110101） —— -11 原码 10001011，数值位取反得反码 11110100，加 1 得补码 11110101。

5. 在本课约定的 8 位有符号 char 且按模 256 回绕的环境下，执行 char c = 128; printf("%d", c); 的输出是

  • A. 128
  • B. 0
  • C. -128
  • D. 127
点开核对答案

答案：C（-128） —— 在上述约定下，char 上限为 127，128 按 8 位有符号二补码回绕为 -128。

6. 下列用户标识符中，合法的是

  • A. 2_buy
  • B. int
  • C. _buy_2
  • D. Text-0
点开核对答案

答案：C（_buy_2） —— 2_buy 数字开头，int 是关键字，Text-0 含减号，均不合法；_buy_2 符合字母/数字/下划线且非关键字。

7. 定义 char c = 'a'; char s[] = "a"; 后，sizeof(c) 与 sizeof(s) 分别是

  • A. c 占 1 字节，s 占 2 字节
  • B. c 占 2 字节，s 占 1 字节
  • C. 都占 1 字节
  • D. 都占 2 字节
点开核对答案

答案：A（c 占 1 字节，s 占 2 字节） —— sizeof(char) 按定义为 1 个 C 字节，所以 c 占 1 字节；s 是包含 a 和末尾空字符的 char 数组，占 2 字节。注意：标准 C 中字符常量本身的类型是 int，sizeof('a') 等于 sizeof(int)，不能与 sizeof(c) 混淆。

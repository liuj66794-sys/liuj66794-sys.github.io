第 8 课 · 数组与字符串

对应笔记 C语言/06-数组 · 教材 P144–P174 · 建议按小节分次学习

能区分数组容量、字符串长度和末尾空字符。

字符数组里还要留一个结束标志

这一节要学会：能区分数组容量、字符串长度和末尾空字符。

数组像一排编号储物格，下标从 0 开始；长度为 4 的数组只有 0、1、2、3 四个合法下标。声明写 4 是格子总数，不是最后一个格子的编号。

C 字符串使用末尾的空字符 \0 告诉函数“文字到这里结束”。它占一个 char 格子，但不计入 strlen 返回的字符串长度。空字符不是字符 '0'，也不是空格。

char s[4]="cat" 恰好装下 c、a、t、\0。若把末尾标记覆盖又没有新的标记，strlen、%s 等会继续寻找结束位置，可能越界。下面所有操作都保持有效结束标记。

查看完整过程，逐步核对

第 1 步

char s[4]="cat";

s[0]：c；s[1]：a；s[2]：t；s[3]：\0

容量 4，字符串长度 3。

第 2 步

s[1]='u';

s[0]：c；s[1]：u；s[2]：t；s[3]：\0

只改一个元素，现在字符串是 cut，长度仍为 3。

第 3 步

s[2]='\0';

s[0]：c；s[1]：u；s[2]：\0；s[3]：\0

字符串在下标 2 结束，长度变成 2；数组容量仍为 4。

核对判断与理由

最后 sizeof s 与 strlen(s) 分别是？

  1. 4 和 2：对。此处 s 是当前作用域中的 char 数组；容量不随内容缩短。
  2. 2 和 2：修改结束标记不会缩小数组对象。
  3. 4 和 4：strlen 数到首个空字符之前，不统计全部容量。

正确判断：4 和 2

换个例子，自己试一次

先独立写出过程，再核对理由。遇到卡点可以回上一小节重走。

要保存字符串 "hello"，不考虑额外输入空间，最少需要多少个 char？写出初始化。

卡住时看提示

数可见字母之后，再为字符串结束标志额外留一个 char。

查看参考过程

至少 6 个：char text[6]="hello";。5 个可见字符加 1 个空字符。也可让编译器推导：char text[]="hello";。

核对判断与理由

char text[]="hello"; 的最后一个元素是什么？

  1. o：o 是最后一个可见字符，它后面还有结束标记。
  2. \0：对。字符串字面量初始化带有末尾空字符。
  3. 字符 0：字符 '0' 的编码不是空字符。

正确判断：\0

一、一维数组：定义、初始化与数组名

定义格式：类型 数组名[常量表达式];，例如 int a[8];。元素为 a[0] ~ a[7]，下标从 0 开始；且数组一旦定义，大小不可改变。

要点正确错误
数组大小文件作用域必须是整型常量表达式；块作用域在 C99 或支持变长数组的 C11 实现中可使用正的变长数组，如 int a[n];文件作用域的 int a[n];（n 普通变量）、int a[2.3];
初始化int a[5]={1,2,3}; 剩余自动补 0列表个数超过长度会警告；不指定长度又不初始化会报错
引用a[0]、a[i]、a[1+1]a[2.3]、a[-1]（越界不报错）

相关信息

记忆口诀

「初始化则值确定，部分赋值补成零；省略长度要数列，不初不省编译停。」

数组名 = 首元素地址 = &a[0]，因此数组名是地址常量：a++、a=a+1 非法；但 a+i ≡ &a[i] 合法，且 a+1 实际加的是 sizeof(元素类型) 字节，不是 1 字节。

本课目标与前置回顾

学习目标

学完这节课，你能做到：

① 判断数组定义与初始化是否合法，并说出违法理由；② 用「数组名是地址常量」解释 a++、a+i、整体赋值等陷阱；③ 默写冒泡排序的趟数与比较次数公式；④ 区分 '\0'、strlen 与 sizeof，并正确选用 strcmp 比较字符串。

温故 · 第 7 课「循环结构」：在 for 循环中，break 与 continue 分别「跳到哪里」？嵌套循环时作用范围如何？

break 直接跳到循环后面的语句，不会执行表达式 3；continue 跳到表达式 3，再判断表达式 2。嵌套时两者都遵循就近原则，只作用于自己所在的那一层。

温故 · 第 6 课「选择进阶」：位运算对什么编码进行？负数右移时左侧补什么？~x 有什么快捷公式？

所有位运算都对补码进行；负数右移左侧补 1；快捷公式 ~x = -x - 1。

相关信息

数组是循环的「最佳搭档」，也是指针章的地基。字符串函数、数组名与地址、冒泡排序都是填空/选择/程序阅读的高频考点。进入巩固阶段，这节课把容易混淆的边界条件钉牢。

二、二维数组：可省行不可省列

定义：int a[3][3]; 逻辑上是 3 行 3 列，内存中仍是连续线性存储。可以把 a 看成由 3 个「行数组」组成的一维数组，a[0] 又是第一行 3 个元素的数组名。

初始化写法结果
int a[2][3]={{1,2,3},{4,5,6}};分行初始化，最直观
int a[2][3]={1,2,3,4,5,6};平铺填充（易漏，不推荐）
int a[2][3]={{1},{2,3}};第 1 行 1,0,0；第 2 行 2,3,0
int a[][3]={1,2,3,4,5,6,7};⌈7/3⌉=3 行，第三行 7,0,0
int a[][3]={{1,2},{},{1,2,3}};行数 = 内层花括号个数 = 3

易错

高频陷阱

二维数组第一维（行数）可以省略，第二维（列数）不可省。int a[3][] 是错的。元素 a[i][j] 之前有 i×N+j 个元素，主对角线 i==j，副对角线 i+j==N-1。

三、冒泡排序的精确计数

升序冒泡：相邻两元素比较，前面大于后面就交换，每一趟把当前最大数沉到末尾。

for(i = 0; i < n-1; i++)          /* 趟数：n-1        */
    for(j = 0; j < n-1-i; j++)    /* 每趟：n-1-i 次   */
        if(a[j] > a[j+1])
        { t = a[j]; a[j] = a[j+1]; a[j+1] = t; }

相关信息

课件修订版公式

n 个数比较 n-1 趟，第 x 趟比较 n-x-1 次。例如 4 个数：第 0 趟比 3 次，第 1 趟比 2 次，第 2 趟比 1 次。注意「第 x 趟」从 0 开始计数。

四、字符数组与字符串

C 没有字符串类型，用字符数组或指针存放字符串。只有用字符串初始化时才自动追加 '\0'。

写法长度内容
char c[] = "abc";4a b c '\0'
char c[5] = {'a','b','c'};5a b c '\0' '\0'（部分初始化补 '\0'）
char c[5] = {'a','b','c','d','e'};5逐字符初始化，无 '\0'

易错

strlen 与 sizeof 的本质区别

strlen 统计字符个数，不含 '\0'，遇到 '\0' 就停止；sizeof 求变量占用的总字节数，含 '\0'。例如 char c[]="abc";：strlen(c)=3，sizeof(c)=4。

五、六大字符串处理函数

函数头文件核心考点
putsstdio.h输出字符串并自动换行，只能一个参数
getsstdio.h输入字符串，空格也收入，只能一个参数
strcatstring.h把串 2 接到串 1 后，数组 1 必须足够大
strcpystring.h复制串 2 到数组 1，解决数组名不能整体赋值的问题
strcmpstring.h按 ASCII 逐字符比较，返回正/0/负；字符串不能用关系运算符比较
strlenstring.h测长度不含 '\0'；涉及字节/内存空间用 sizeof

相关信息

输入细节

scanf("%s", c); 中 c 本身就是地址，不能写成 &c；scanf 遇空格停止，gets 可收空格。

六、先回忆，再自测

合上笔记默写：数组名是什么？a++ 为什么非法？a+1 实际加多少字节？

数组名是首元素地址（&a[0]），属于地址常量，因此 a++、a=a+1 都会改变常量，非法。a+1 实际加 sizeof(元素类型) 字节，对 int 数组就是 4 字节。

默写二维数组的「可省」规则和 a[i][j] 位置公式

二维数组初始化时，第一维（行数）可以省略，第二维（列数）不可省。a[i][j] 之前有 i×N+j 个元素，它是第 i×N+j+1 个元素。主对角线 ij，副对角线 i+jN-1。

对比 strlen 与 sizeof；字符串比较为什么不能直接用 >、==？

strlen 测长度不含 '\0'，sizeof 求占用字节数含 '\0'。数组名是地址常量，用关系运算符比较字符串实际上是在比较两个地址，不是比较字符内容，必须用 strcmp。

七、测验（点击选项作答）

1. 下列数组定义或初始化中，合法的是

  • A. 文件作用域的 int a[n];（n 为普通变量）
  • B. int a[2.3];
  • C. int a[5] = {0};
  • D. 块作用域的 int a[];（无 extern、无初始化）
点开核对答案

答案：C（int a[5] = {0};） —— 本题把 A 明确为文件作用域数组：文件作用域数组长度必须是整型常量表达式，所以 int a[n]（n 为普通变量）不合法；块作用域在 C99 或支持变长数组的 C11 实现中可有变长数组，但不属于此选项前提。D 在块作用域既不指定长度又不初始化，不能定义该自动数组；int a[5]={0} 是标准全零写法。

2. 关于数组名的说法，正确的是

  • A. 数组名是变量，a++ 合法
  • B. a+i 等价于 &a[i]
  • C. a+1 实际只加 1 个字节
  • D. a = a+1 可以改变数组位置
点开核对答案

答案：B（a+i 等价于 &a[i]） —— 数组名是地址常量，a++、a=a+1 均非法；a+1 实际加 sizeof(元素类型) 字节；a+i 与 &a[i] 等价。

3. n 个数进行不提前退出的冒泡排序，趟编号 x 从 0 到 n−2。总趟数与第 x 趟比较次数为

  • A. n 趟，第 x 趟 n-x 次
  • B. n-1 趟，第 x 趟 n-x-1 次
  • C. n 趟，第 x 趟 n-x-1 次
  • D. n-1 趟，第 x 趟 n-x 次
点开核对答案

答案：B（n-1 趟，第 x 趟 n-x-1 次） —— 课件修订版公式：n 个数比较 n-1 趟，第 x 趟比较 n-x-1 次。注意 x 从 0 开始。

4. 对于 int a[][3]={1,2,3,4,5,6,7}，第一维与第三行分别是

  • A. 2 行，第三行 7,0,0
  • B. 3 行，第三行 7,0,0
  • C. 3 行，第三行 0,0,7
  • D. 2 行，第三行 0,0,7
点开核对答案

答案：B（3 行，第三行 7,0,0） —— 省略第一维时按 ⌈元素总数/列数⌉ 计算：⌈7/3⌉=3 行。按行优先填充，第三行只有 7，其余补 0。

5. char c[]="abc"; 与 char d[5]={'a','b','c'}; 的长度和内容区别是

  • A. c 长 3，d 长 3，都无 '\0'
  • B. c 长 4，d 长 3，都含 '\0'
  • C. c 长 3，d 长 5，都含 '\0'
  • D. c 长 4，d 长 5，都含 '\0'
点开核对答案

答案：D（c 长 4，d 长 5，都含 '\0'） —— 字符串初始化自动加 '\0'，故 c 为 4 字节；d 指定长度 5 且部分初始化，剩余补 '\0'，长度 5。

6. 执行 strcmp("abc", "Abc") 的返回值是

  • A. 负数
  • B. 正数
  • C. 0
  • D. 无法确定
点开核对答案

答案：B（正数） —— strcmp 按 ASCII 逐字符比较，'a'(97) > 'A'(65)，所以第一个字符已分出大小，返回正数。

能解释为什么把整数除法结果存进 double 也不能补回小数。

把表达式拆成类型、运算和赋值

这一节要学会：能解释为什么把整数除法结果存进 double 也不能补回小数。

像把已经切掉的小数部分放进更大的盒子：盒子变大不会把丢掉的内容找回来。表达式先按操作数类型计算，之后才转换成目标变量的类型。

7 和 2 都是 int，7/2 得到整数 3；赋给 double 后是 3.0。只要其中一个操作数先成为 double，例如 7.0/2，除法才得到 3.5。整数除法向零截断；余数 % 用于整数操作数。

优先级决定表达式怎样分组，不等于操作数总按从左到右求值。学习时先给表达式加括号，再标各子表达式类型；不要用含有未排序的重复自增表达式来猜一个“唯一答案”。

查看完整过程，逐步核对

第 1 步

double a = 7 / 2;

7 / 2：int: 3；a：3.0

除法发生在赋值之前，两边都是整数。

第 2 步

double b = 7.0 / 2;

7.0 / 2：double: 3.5；b：3.5

2 转换后参与浮点运算。

第 3 步

double c = (double)(7 / 2);

先除：3；c：3.0

外层强制转换发生得太晚。

第 4 步

double d = (double)7 / 2;

先转：7.0；d：3.5

先改变操作数类型，再计算除法。

核对判断与理由

double x = 5 / 2; 的 x 是？

  1. 2.5：先做整数除法，小数部分已截去。
  2. 2.0：对。整数结果 2 转成 double 得到 2.0。
  3. 无法赋值：int 可以转换成 double，这不是类型错误。

正确判断：2.0

换个例子，自己试一次

先独立写出过程，再核对理由。遇到卡点可以回上一小节重走。

把 int a=5, b=2; double avg=a/b; 改成保留小数的表达式，并说明转换应放在哪里。

卡住时看提示

沿着赋值右侧读：在除法开始前，至少让一个操作数先成为 double。

查看参考过程

写 double avg=(double)a/b;。先把 a 转成 double，再做除法得到 2.5。写 (double)(a/b) 只能把已经得到的 2 转成 2.0。

核对判断与理由

哪种写法在除法前完成转换？

  1. (double)(a/b)：括号里的整数除法已经完成。
  2. (double)a/b：对。转换只作用于 a，随后参与浮点除法。
  3. double avg=a/b：目标变量类型不会倒过来改变右侧运算。

正确判断：(double)a/b

一、优先级：先记骨架，再记右结合

15 级优先级不必逐级死背，先背这条骨架链（高 → 低）：

括号/下标 > 单目 > 算术 > 移位 > 关系 > 位（与>异或>或）> 逻辑 > 条件 > 赋值 > 逗号

两条使用规则：

  • 不同优先级看级别——级别高的先算；
  • 相同优先级看结合方向——绝大多数从左至右（如 5+6-2 = (5+6)-2）。

易错

只有三种结合方向是「从右至左」

① 单目运算符（! ~ ++ -- - (类型) * & sizeof，2 级）；② 条件 ?:（13 级）；③ 赋值与复合赋值（14 级）。选择题问「右结合的运算符」就从这三档里找。2025 真题第 18 题：~ 是 2 级单目，优先级高于 /、<<、&&。

本课目标与前置回顾

学习目标

学完这节课，你能做到：

① 背出优先级关键链「括号 > 单目 > 算术 > 移位 > 关系 > 位与/异或/或 > 逻辑 > 条件 > 赋值 > 逗号」，并说出三种右结合的运算符；② 口算 7/3、7%3、-5%3、7/2.0；③ 辨析 ++i 与 i++，判断 6++、(a+1)++ 不合法；④ 一步一步推出必考题 a += a -= a*a；⑤ 写出逗号表达式、赋值表达式的取值规则，并完成代数式 → C 表达式的转写。

温故 · 第 2 课「数据的表示：数制、补码与常量」：负数的反码、补码怎么求？-11 的 8 位原码、反码、补码各是什么？

反码：符号位不变，数值位取反；补码：反码 + 1。-11：原码 10001011、反码 11110100、补码 11110101。

温故 · 第 1 课「C 程序的全貌与编译四步骤」：.c 源程序、.obj 目标程序、.exe 文件中，哪一种能被计算机直接执行？

源程序（.c）和目标程序（.obj）都不能被计算机直接执行，只有 .exe 能；能被计算机直接执行的语言也只有机器语言。

相关信息

为什么这一课单独成课

上一课的数制与补码是「数据怎么存」，这一课是「数据怎么算」——第二章的 §7 是全章最重的一节（★★★★★）。2025 真题卷第 2、13、18 题全部出自这里：表达式求值、a+=a-=a*a、优先级最高的运算符。

二、算术运算符：/ 整除、% 取余、++ 自增

2.1 除法 / 与取余 %

规则例
两侧均为整数 → 只保留整数部分1/3=0、7/3=2、1/2=0
有一侧是小数 → 结果为 double7/2.0=3.5、1.0/2=0.5
% 的操作数必须是整型【经典选择】4*2.5%3 不合法（2.5 是实数）
% 的余数符号与被除数一致-5%3=-2、5%-2=2、-5%-2=-2

经典易错：3.5+1/2 = 3.5 + 0 = 3.5，不是 4.0——1/2 先按整除算成 0。

2.2 自增自减 ++ --

  • 只能用于变量：6++、(a+1)++、(a++)++ 全部不合法【常考易错】；
  • 前置 ++i：先加 1 再使用；后置 i++：「后置看整体，之后变量必改值」——先把 i++ 整体当当前值用，语句之后 i 变为 i+1。

例：i=10 时，int a = i++; → a=10，i=11；int a = ++i; → a=11，i=11。

c 语言例：a=3, b=9 时 c = b/++a → a 先变 4，c = 9/4 = 2。

三、类型转换：混合运算、强制转换与赋值转换

  • 混合运算：操作数中有 float/double → 结果为 double；30+2.5*3-1/2 = 30+7.5-0 = 37.5；'A'+3 = 68（char 按 ASCII 参与运算，68 是 'D'）。
  • 强制转换 (类型)(表达式)：优先级 2（单目），(int)x+y 只转 x。不改变变量原值：x=3.14 时 (int)x 这个整体的值是 3，x 仍是 3.14。真题：((double)4/2)+2.5 = 2.0+2.5 = 4.5。
  • 赋值自动转换：实→整舍去小数（int a=3.14 → a=3）；整→实补 0；char→int 放 ASCII 值。链式赋值：d = b = c = a = 3.14;（a、b 为 int）→ a=3, b=3, c=3.0, d=3.0。

四、赋值与复合赋值【必考】

  • 赋值号左侧不可以是算式：a+b=2、(a=b)=c、(a++)=8 均不合法；
  • 赋值表达式本身也有值：x=(a=1)+(b=3) → x=4；
  • 复合赋值 += -= *= /= %= 等：x *= a+b ≡ x = x*(a+b)——右边整体要加括号。

易错

必考题：a=10，求 a += a -= a*a

右结合 → 先算 a -= a*a：a = 10 − 100 = −90；再算 a += (−90)：a = −90 + (−90) = −180。

同型题 n=2：n += n -= n*n → 先 2−4=−2，再 −2+(−2) = −4。2025 真题第 13 题同款：a=6 时结果为 −60。

五、逗号表达式

  • 从左到右逐个计算，整体值 = 最后一个表达式的值：a=(10,20,30) → a=30；
  • 优先级最低（15 级）——y = a=1, a+5, b=a+10 里赋值优先级高于逗号，先算 y = a=1；
  • 中途变量被改变要跟住：double x 时 x++, x+10, x=0 的值为 0.0。

代数式转写两条硬规矩：乘号不能省（3a 写 3*a）；除法整体要括号（a÷(3+2) 写 a/(3+2)）。

六、先回忆，再自测

优先级骨架链是什么？哪三档是右结合？

括号/下标 > 单目 > 算术 > 移位 > 关系 > 位（与>异或>或）> 逻辑 > 条件 > 赋值 > 逗号。右结合：单目、?:、赋值（含复合赋值）。

7/3、7%3、-5%3、5%-2、7/2.0 各是多少？

2；1；−2（余数符号同被除数）；2；3.5（有实数参与结果为 double）。

a=10，a += a -= a*a 的完整推导？

右结合：先 a -= a*a 得 a=10−100=−90；再 a += (−90) 得 a=−180。口诀：先把右边吃掉自己，再吃一遍。

(a+1)++ 合法吗？++i 与 i++ 的口诀？

不合法——自增只能用于变量。前置先加后用；后置「后置看整体，之后变量必改值」。

七、测验（点击选项作答）

1. 运算对象必须是整型的运算符是

  • A. /
  • B. +
  • C. %
  • D. <=
点开核对答案

答案：C（%） —— %（取余）要求两个操作数都是整型；/ 和 + 允许实型，关系运算符也没这个限制。

2. 设 a=10，表达式 a += a -= a*a 执行后 a 的值为

  • A. 100
  • B. -180
  • C. -90
  • D. 0
点开核对答案

答案：B（-180） —— 右结合：先 a -= 100 得 −90，再 a += (−90) 得 −180。2025 真题第 13 题（a=6）同型，答案 −60。

3. 表达式 3.5 + 1/2 的值是

  • A. 3.5
  • B. 4.0
  • C. 3.0
  • D. 4.5
点开核对答案

答案：A（3.5） —— 1/2 两侧都是整数，整除得 0；再与 3.5 相加得 3.5。别把 1/2 当成 0.5。

4. 下列运算符中，结合方向为「从右至左」的是

  • A. +
  • B. &&
  • C. ,
  • D. ?:
点开核对答案

答案：D（?:） —— 右结合只有三档：单目（2 级）、条件 ?:（13 级）、赋值（14 级）。+ 、&& 、逗号都是从左至右。

5. int i=10; 执行 int a = i++; 后 a、i 的值分别是

  • A. 11、11
  • B. 10、11
  • C. 10、10
  • D. 11、10
点开核对答案

答案：B（10、11） —— 后置 i++「看整体」：a 拿到当前值 10，语句之后 i 变 11。若写 ++i 则 a、i 都是 11。

6. 设 double x=3.14; 表达式 (int)x 的值为 3，则执行后 x 的值为

  • A. 3
  • B. 3.0
  • C. 3.14
  • D. 4.0
点开核对答案

答案：C（3.14） —— 强制转换不改变变量原值：(int)x 只是这个整体的值取 3，x 本身仍是 3.14。

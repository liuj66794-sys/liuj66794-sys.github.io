能追踪 case 命中后的穿透，而不是把每个 case 当作独立 if。

switch：入口与出口分开看

这一节要学会：能追踪 case 命中后的穿透，而不是把每个 case 当作独立 if。

把 switch 想成从指定楼层进入楼梯：case 决定入口，break 决定出口。进入后没有出口，就会继续走到下面的语句，不会再重新匹配下一个 case。

switch 的控制表达式求值后选择匹配标签；没有匹配才使用 default（如果有）。case 标签本身不阻止后续语句执行。break 跳出最内层的 switch 或循环。

if/else 是另一套规则：没有花括号时，else 与最近且尚未配对的 if 结合。写嵌套条件时主动加花括号，再用缩进表达结构，不能让缩进替代语法判断。

查看完整过程，逐步核对

第 1 步

int k=1, s=0;

k：1；s：0

将执行 switch(k)。

第 2 步

case 1: s += 10;

s：10

匹配入口是 case 1。这一段没有 break。

第 3 步

case 2: s += 20; break;

s：30

顺着执行 case 2 的语句，不要求 k 等于 2。随后退出 switch。

第 4 步

default: s=99; /* 本例未执行 */

最终 s：30

已经 break，不会进入 default。

核对判断与理由

上例如果 k=2，s 最后是多少？

  1. 10：不会从 case 1 进入。
  2. 20：对。直接从 case 2 开始，执行加 20 后退出。
  3. 30：只有从 case 1 进入且穿透时才加两次。

正确判断：20

换个例子，自己试一次

先独立写出过程，再核对理由。遇到卡点可以回上一小节重走。

同一 switch 中，让 k=1 时只加 10，应在何处补上什么？

卡住时看提示

找到 case 1 做完加法的位置。要在进入下一标签下的语句前离开 switch。

查看参考过程

在 case 1 的 s+=10; 后添加 break;。这能阻止穿透到 case 2，但不会结束整个函数。

核对判断与理由

switch 放在 for 循环内，case 中的 break 退出哪一层？

  1. 整个函数：返回函数需要 return；break 的作用域更小。
  2. 最内层 switch：对。它退出最内层可被 break 终止的结构，即这里的 switch。
  3. 外层 for：switch 更近，外层循环仍可继续。

正确判断：最内层 switch

一、嵌套 if-else 与 else 配对

核心规则：C 语言规定，else 总是与它前面最近的、尚未配对的 if 配对，与代码缩进无关。出题人常用缩进把 else「推远」，不能上当。

易错

两个高频编译错误

  • 内嵌语句若有多条却不用 { }，第二条语句会把 if 和 else 隔开，导致 else without a previous if。
  • 同一 if 后出现两个 else，编译器会报 else 过多（配对冲突）。

用花括号改变配对：else 总与最近的、未配对的 if 结合，花括号能改变这个「最近」。

if (a < b)
    if (c < d) x = 1;
else x = 2;      /* else 被最近的内层 if(c<d) 抢走，
                    等价于 if (a < b) { if (c < d) x = 1; else x = 2; } */

若给内层 if 加上花括号：

if (a < b) { if (c < d) x = 1; }
else x = 2;      /* 花括号隔开配对，else 归外层 if(a<b) */

相关信息

快速验证技巧

对等价判断题，用特殊值代入：0、1、-1、2。例如判断 if(a) 与 if(a!=0) 是否等价，分别代入 0 和非 0 即可。

本课目标与前置回顾

学习目标

学完这节课，你能做到：

① 根据输入数据，逐行追踪无 break 的 switch 执行路径并算出结果；② 面对多层嵌套 if-else，准确判断 else 与哪个 if 配对；③ 不依赖编译器，笔算含负数、取反、移位、位与或异或的表达式的值。

温故 · 第 5 课「选择结构」：&& 与 || 的短路规则分别是什么？被短路意味着什么？

&& 左侧为 0（假）时右侧不执行，整体为 0；|| 左侧非 0（真）时右侧不执行，整体为 1。被短路时右侧的自增、赋值可能根本不发生。

温故 · 第 4 课「顺序结构：printf 与 scanf」：用 scanf 给 double 变量输入，格式符必须写什么？scanf 支持类似 %5.2f 的写法吗？

必须用 %lf，%f 无法正确输入 double；scanf 也没有 %m.nf 形式的输入，scanf("%5.2f", &x) 这种写法直接判错。

相关信息

为什么这节课重要

else 配对、case 穿透、位运算笔算，是选择结构这一章「程序阅读题」的三大题源。它们都考得很细：else 跟谁走、break 漏写会怎样、负数右移补 0 还是补 1……这节课把笔记后半压缩成可检索的回忆点。

二、switch 与 case 穿透

规则要点
switch 表达式只能是整型或字符型，不能是实型
case 后必须是整型/字符型常量或常量表达式，不能是变量
case 值必须唯一；'a' 与 97 重复会报错
default同一 switch 只能有一个；位置不影响匹配顺序
入口 / 出口case 是入口，break 是出口；无 break 就继续执行下一个 case

易错

case 穿透怎么读

匹配到某个 case 后，从这个 case 开始顺序往下执行，直到遇见 break 或 switch 结束。default 写在最前面也不会先执行——先全部 case 匹配一遍，都不中才走 default。

嵌套 switch：内层 break 只结束所在（最近）的内层 switch；外层 case 若无 break，仍会穿透到外层下一个 case。

三、位运算（对补码运算）

运算符优先级规则示例
~2按位取反，符号位也变~3 = -4，~-3 = 2
<<5左移，右侧补 06<<2 = 24，等价 m×2ⁿ
>>5本课按常见有符号二补码算术右移：正数左补 0，负数左补 1；标准 C 对负有符号数右移的结果依实现而定-16>>2 = -4；此例恰好整除，负奇数算术右移需向下取整
&8按位与：一 0 则 03&6 = 2
^9异或：相同 0，不同 13^6 = 5
|10按位或：一 1 则 13|6 = 7

相关信息

速算口诀

以下按常见有符号二补码算术右移约定：所有位运算都对补码进行；负数右移左侧补 1；取反有规律 ~x = -x - 1。标准 C 对负有符号数右移的结果依实现而定；笔算时先把数写成 8 位或 32 位补码，再逐位运算，最后转回真值。

四、顺带巩固：条件表达式 ?:

?: 是 C 语言唯一的三目运算符，优先级高于赋值、低于关系和算术，从右至左结合。

max = a > b ? a : b;           /* 等价于 if-else */

a > b ? a : c > d ? c : d     /* 右结合：a>b?a:(c>d?c:d) */

五、先回忆，再自测

合上笔记：else 到底跟谁配对？缩进有没有影响？

else 与前面最近的、尚未配对的 if 配对；与缩进无关。花括号可以把内层 if-else 包起来，从而改变外层 else 的归属。

switch 中 case 和 break 各是什么角色？default 写在最前面会先执行吗？

case 是入口，break 是出口；无 break 就继续执行下一个 case，称为穿透。default 位置不影响匹配，先匹配所有 case 都不中时才走 default。

位运算对什么编码进行？负数右移补什么？~x 有什么快捷公式？

按本课常见有符号二补码算术右移约定：对补码运算；负数右移左侧补 1；快捷公式 ~x = -x - 1。移位数须小于类型位宽：有符号非负数左移仅在结果可表示时可按乘 2ⁿ 理解；算术右移按除 2ⁿ 后向下取整理解（如 -5>>1=-3，与 C 的 -5/2=-2 不同）；标准 C 对负有符号数右移的结果依实现而定。

六、测验（点击选项作答）

1. 执行下面程序段后，输出结果是

  • A. 输出 80
  • B. 输出 8070
  • C. 输出 807060
  • D. 输出 70
点开核对答案

答案：B（输出 8070） —— 匹配 case 'B' 输出 80，其后无 break，穿透到 case 'C' 输出 70 后遇 break 退出；case 'A' 在 B 之前不会被匹配，case 'D' 在 break 之后不执行。

2. 执行下列程序后，变量 i 的值为

  • A. 10
  • B. 11
  • C. 12
  • D. 13
点开核对答案

答案：D（13） —— 匹配 case 10，i 变为 11；后面没有 break，依次穿透 case 11（12）、default（13），最后退出 switch。

3. 以下程序输出结果是

  • A. a=1, b=0
  • B. a=2, b=1
  • C. a=1, b=1
  • D. a=2, b=2
点开核对答案

答案：B（a=2, b=1） —— 外层匹配 case 1；内层 switch(y) 匹配 case 0，a 自增 1，内层 break 只退出内层 switch；外层 case 1 没有 break，继续穿透到 case 2，a、b 各加 1，遇 break 退出。

4. 下列 switch 用法中，不会导致编译错误的是

  • A. switch('A') 后接字符常量
  • B. case 1.5: 后接实型常量
  • C. switch(3.5) 使用实型表达式
  • D. case 'a': 与 case 97: 同时出现
点开核对答案

答案：A（switch('A') 后接字符常量） —— switch 表达式只能是整型或字符型；case 后也只能是整型/字符型常量；'a' 的 ASCII 码就是 97，与 case 97 重复会报错。只有 A 合法。

5. 在本课采用常见有符号二补码算术右移的约定下，表达式 -16 >> 2 的值是

  • A. -4
  • B. -8
  • C. -2
  • D. 4
点开核对答案

答案：A（-4） —— 在题设约定下，负数右移左侧补 1，此处 -16 可被 4 整除，所以 -16>>2 = -4；正数右移左侧补 0。

6. 已知 int a=5, b=7，表达式 (a ^ b) & ~(-2) 的值是

  • A. 0
  • B. 2
  • C. 5
  • D. 7
点开核对答案

答案：A（0） —— 5 ^ 7 = 2（0101 ^ 0111 = 0010）；~(-2) 按公式 -x-1 得 1；2 & 1 = 0。

能使用访问标记避免重复入队，并说明遍历顺序依赖邻接顺序。

BFS 的队列记录接下来访问谁

这一节要学会：能使用访问标记避免重复入队，并说明遍历顺序依赖邻接顺序。

找社交关系时，BFS 先找一层朋友，再找朋友的朋友；DFS 则沿一条关系一直深入，走不通再回退。前者常用队列，后者常用递归或栈。

本例无向图有边 AB、AC、BD、CD，从 A 出发，邻居按字母顺序查看。BFS 在发现结点并入队时就标记已访问，可避免 B、C 都把 D 重复加入。

图的遍历序列通常不是唯一的：起点和邻接顺序都会影响结果。若图不连通，单次从一个起点搜索只能覆盖它所在的连通部分，还需从未访问顶点继续。

无向图：AB、AC、BD、CD 四条边。高亮结点对应演示当前处理的结点。

查看完整过程，逐步核对

第 1 步

发现 A，标记并入队

队列（头→尾）：A；输出：空

边：AB AC BD CD

本演示在出队时输出，发现时标记。

第 2 步

出队 A，发现 B、C

队列：B C；输出：A

按字母顺序入队，B、C 立即标记。

第 3 步

出队 B，发现 D

队列：C D；输出：A B

A 已访问，跳过；D 首次发现。

第 4 步

出队 C，D 已被标记

队列：D；输出：A B C

不能再次把 D 入队。

第 5 步

出队 D，队列为空

队列：空；输出：A B C D

本图所有顶点均已处理。

核对判断与理由

为什么处理 C 时不再加入 D？

  1. D 不与 C 相邻：图里明确有边 CD。
  2. D 已在发现时标记：对。访问标记防止重复发现和无限兜圈。
  3. 队列最多放两个：队列容量不是这里跳过 D 的原因。

正确判断：D 已在发现时标记

换个例子，自己试一次

先独立写出过程，再核对理由。遇到卡点可以回上一小节重走。

同一图、同一起点、同一字母邻接顺序，用 DFS 写出首次访问序列。

卡住时看提示

DFS 从 A 先选字母较小的 B，再向 D 深入；只记录第一次访问。

查看参考过程

A B D C。先由 A 深入 B，再深入 D，再由 D 到 C；遇到已访问顶点跳过，再逐层返回。它与 BFS 的 A B C D 不同。

核对判断与理由

换一种邻接存储顺序，合法遍历序列可能变化吗？

  1. 可能：对。应按题目给出的起点和邻接顺序推演。
  2. 绝不可能：遍历规则不自动规定同层邻居的先后。
  3. 只会改变顶点数量：访问次序改变不会改变图本身的顶点数。

正确判断：可能

一、图的基本概念：G=(V, E)

图 G = (V, E)：顶点的有穷非空集合 V，加上边的集合 E。

  • 图中数据元素叫顶点，不允许没有顶点（有穷非空性）——这一点区别于空表、空树；但边集可以为空；
  • 线性表元素是一对一，树是层次（一对多）关系，图是多对多关系，用边表示。
概念定义
无向图 / 有向图边都无向 / 边都有向（有向边称弧 <Vi,Vj>，箭头端为弧头）
无向完全图任意两顶点都有边：n(n−1)/2 条边
有向完全图任意两顶点都有方向相反的两条弧：n(n−1) 条弧
顶点的度与该顶点相关联的边数；有向图：度 = 入度 + 出度
邻接无向边 (V1,V2) 两顶点互为邻接点；无向边用小括号、有向边用尖括号
路径 / 回路顶点序列 / 首尾相同的路径
连通图、连通分量无向图任意两点有路径 = 连通图；连通分量 = 极大连通子图（连通图的连通分量是其本身）
强连通图、强连通分量有向图每一对顶点 Vi↔Vj 都有路径；强连通分量 = 极大强连通子图
权与网边/弧上的数字叫权；带权图 = 网
生成树连通图包含全部顶点、任意两点仅一条通路：边数 = 顶点数 − 1，无环
生成森林非连通图各连通分量的生成树组成的森林

相关信息

判断小抄

n 个顶点，边数 < n−1 → 一定不连通；> n−1 → 必有环。生成树的边数恰好等于顶点数 − 1。

相关信息

高频推论

有向图所有顶点出度之和为 s，则所有顶点度数之和为 2s（度数和 = 出度和 + 入度和 = s + s）。

本课目标与前置回顾

学习目标

学完这节课，你能做到：

① 说出图 G=(V, E) 的两个要点——顶点集有穷非空、边集可以为空，并背出无向/有向完全图的边（弧）数；② 用「极大」两个字说清连通分量与强连通分量，用「边数比 n−1」秒判连通与环；③ 在邻接矩阵中读出度与入度，口算空间 O(n²) 与有效元 2e 个；④ 用栈推 DFS 序列、用队列推 BFS 序列，并解释序列为什么可能不唯一。

温故 · 第 22 课「赫夫曼树与编码」：n 个叶子的赫夫曼树，总结点数是多少？树中有没有度为 1 的结点？

总结点数为 2n−1；不存在度为 1 的结点——每次合并都新增一个度为 2 的内部结点，共新增 n−1 个。

温故 · 第 21 课「树、森林与二叉树的转换和存储」：树转二叉树的规则是什么？转换后根结点的右子树有何特征？

左孩子 = 原来的孩子，右孩子 = 原来的兄弟（兄弟连线 → 只留第一孩子 → 顺时针转 45°）。转换形态唯一，且根的右子树必为空——根没有兄弟。

相关信息

为什么现在复习图

图是数据结构「最重」的一章：基本概念、存储、遍历是选择题的常客，而下一课的最小生成树、最短路径、拓扑排序、关键路径全靠这节课的地基。广东专升本卷子里，完全图边数、连通分量、邻接矩阵读度、DFS/BFS 序列都是大题高频区的送分点——先把这节课的「数字」和「口诀」焊死。

二、图的存储：邻接矩阵与邻接表

2.1 邻接矩阵法

一维数组存顶点信息 + 二维数组（邻接矩阵）存边信息。

  • 无向图：矩阵一定对称；第 i 行（或第 i 列）的非零元素个数 = 第 i 个顶点的度；
  • 有向图：第 i 行非零元 = 出度；第 i 列非零元 = 入度；
  • 网：无边处用 ∞（无权图用 0）；
  • 空间复杂度 O(n²)（与顶点数有关）；n 个顶点 e 条边的无向图占 n² 个存储，有效元 2e 个，无效 n²−2e 个。

2.2 邻接表法

边数相对较少时邻接矩阵浪费空间 → 对每个顶点建一个单链表：表头结点存顶点信息并指向第一个边结点，边结点存邻接顶点序号。

  • 无向图：每条边存两遍；顶点 Vi 的度 = 该顶点邻接表中边结点个数；
  • 有向图：边结点个数 = 该顶点的出度（求入度需遍历全表或用逆邻接表）。

易错

⚠️ 真实缺口提醒

邻接多重表出现在考点列表中，但课件未展开讲解；逆邻接表也只在「有向图求入度」处一笔带过。这两块本课不展开，记住名字与用途即可，考前以笔记 数据结构/16-图 为准。

三、图的遍历：DFS 与 BFS

3.1 深度优先遍历 DFS

  1. 访问出发点 v，标记已访问；
  2. 访问与 v 邻接且未访问的顶点 w；
  3. 再选与 w 邻接且未访问的顶点 q……当某顶点的邻接点全被访问过，依次回退到最近被访问的顶点，若其还有未访问邻接点则继续。

口诀：「不撞南墙不回头」；借助栈实现。

3.2 广度优先遍历 BFS

  1. 访问出发点 v，标记已访问；
  2. 访问 v 的所有未访问邻接点，按序入队列；
  3. 依次出队，访问出队结点的未访问邻接点并入队……直到队空（按层扩展）。

借助队列实现。

遍历辅助结构过程要点序列唯一性
DFS 深度优先栈一路向下，「不撞南墙不回头」，走不动依次回退都可能不唯一
BFS 广度优先队列按层扩展，出队一个、把它未访问的邻接点按序入队都可能不唯一

相关信息

为什么序列不唯一

DFS/BFS 序列都取决于邻接点的访问次序，所以同一图的遍历序列可能不唯一；遍历经过的边保留、删去其余边，得到的深度/广度优先生成树也有多种。

先回忆，再自测

无向完全图和有向完全图的边（弧）数各是多少？

无向完全图 n(n−1)/2 条边；有向完全图 n(n−1) 条弧。口诀：有向翻倍——每对顶点要方向相反的两条弧。

连通分量、强连通分量怎么定义？题眼是哪两个字？

连通分量 = 无向图的极大连通子图；强连通分量 = 有向图的极大强连通子图。漏掉「极大」两个字就是易错写法。

邻接矩阵里怎么读度？空间开销多大？

无向图矩阵一定对称，第 i 行（或列）非零元个数 = 度；有向图第 i 行非零元 = 出度、第 i 列非零元 = 入度；空间 O(n²)，n 顶点 e 边的无向图有效元 2e 个。

DFS 与 BFS 分别借助什么结构？口诀是什么？序列唯一吗？

DFS 借助栈，口诀「不撞南墙不回头」；BFS 借助队列，按层扩展。两种遍历序列都可能不唯一（取决于邻接点访问次序）。

测验（点击选项作答）

1. n 个顶点的有向图，所有顶点出度之和为 s，则所有顶点度数之和为

  • A. s
  • B. 2n
  • C. 2e
  • D. 2s
点开核对答案

答案：D（2s） —— 度数和 = 出度和 + 入度和 = s + s = 2s。别和邻接矩阵的 2e 记混：那是有向图之外、无向图矩阵有效元的结论。

2. n 个顶点的无向完全图的边数为

  • A. n(n−1)
  • B. n(n+1)
  • C. n(n−1)/2
  • D. n(n+1)/2
点开核对答案

答案：C（n(n−1)/2） —— 无向完全图任意两顶点都有边，共 n(n−1)/2 条；有向完全图才是 n(n−1) 条弧。这是本章最高频的送分公式。

3. n 个顶点的无向连通图，其连通分量个数为

  • A. 1
  • B. 0
  • C. n−1
  • D. n
点开核对答案

答案：A（1） —— 连通图任意两点间都有路径，其极大连通子图就是整个图本身，所以连通分量个数是 1。

4. 把 n 个顶点连成一个连通图，至少需要多少条边

  • A. n
  • B. n+1
  • C. 2n
  • D. n−1
点开核对答案

答案：D（n−1） —— 至少 n−1 条，恰好是生成树的边数。判断小抄：边数 < n−1 一定不连通，> n−1 必有环。

5. n 个顶点 e 条边的无向图，其邻接矩阵中有效元素个数为

  • A. e
  • B. n²
  • C. n²−2e
  • D. 2e
点开核对答案

答案：D（2e） —— 无向图矩阵对称，每条边对应两个有效元素，共 2e 个；无效元是 n²−2e 个，矩阵总占 n² 个存储单元。

6. n 个顶点 e 条边的有向图，其邻接矩阵中有效元素个数为

  • A. e
  • B. 2e
  • C. n²−e
  • D. n²
点开核对答案

答案：A（e） —— 有向图每条弧只对应矩阵中一个元素，有效元素共 e 个；无向图才是 2e 个。

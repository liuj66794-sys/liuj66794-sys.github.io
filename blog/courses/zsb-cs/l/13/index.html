能通过对象或指针修改同一个结构体，并用成功分支管理文件。

先看对象，再看访问路径

这一节要学会：能通过对象或指针修改同一个结构体，并用成功分支管理文件。

结构体像一张学生档案，把姓名、分数等不同字段归在同一个对象里。对象名.成员访问该对象的字段；指针->成员先找到对象再访问字段。

struct Student { int id; int score; }; 定义类型形状；struct Student s={7,80}; 才创建对象。若 p=&s，则 p->score 与 (*p).score 访问同一个成员，括号不能省略。

文件也要先得到有效访问入口。FILE *fp=fopen("data.txt","r"); 后先判断 fp 是否为空；仅在成功时读取，核对读取函数结果，并在使用结束后 fclose(fp)。打开失败后不能继续把空指针传给读取函数。

查看完整过程，逐步核对

第 1 步

struct Student s={7,80};

s.id：7；s.score：80

按成员声明顺序初始化。

第 2 步

struct Student *p=&s;

s.score：80；p：&s

p → s

创建访问 s 的指针，档案没有复制。

第 3 步

p->score=90;

s.score：90；(*p).score：90

p → s

两种写法到达同一个字段。

第 4 步

struct Student copy=s; copy.score=60;

s.score：90；copy.score：60

结构体赋值产生另一个对象的成员值；改 copy 的整数字段不改 s。

核对判断与理由

p 指向 s，修改 p->score 会怎样？

  1. 只改 p 中的地址：赋值左侧是成员访问，不是 p 本身。
  2. 改 s.score：对。沿 p 找到 s，再修改其 score。
  3. 生成新的 Student：成员写入不会额外创建结构体对象。

正确判断：改 s.score

换个例子，自己试一次

先独立写出过程，再核对理由。遇到卡点可以回上一小节重走。

fopen 返回空指针时，下一步应继续 fscanf 还是进入失败处理？说明理由。

卡住时看提示

先判断是否取得有效文件流。打开失败与打开成功后的读取失败是两个检查点。

查看参考过程

进入失败处理。空指针表示未取得有效文件流，不能继续读写或调用 fclose(NULL)。成功打开后，也要检查读取是否成功，最后关闭有效文件流。

核对判断与理由

哪条执行顺序合理？

  1. fopen→直接读取→判断是否为空：判断太晚，读取时就可能已经使用无效流。
  2. fopen→检查成功→读取并检查→关闭：对。先取得资源，再使用，使用后释放。
  3. 读取→fopen→关闭：必须先成功打开才能通过对应文件流读取。

正确判断：fopen→检查成功→读取并检查→关闭

一、结构体：声明、定义与初始化

声明结构体就是定义一种新类型，类型本身不占内存，只有定义变量后才开辟空间。

struct Student
{
    int num;
    char name[20];
    float score;
};              /* ← 末尾分号不能少 */
要点正确做法常见错误
成员规则成员只能定义变量在成员处直接赋初值或写常量
整体初始化只能在定义变量时整体初始化先定义再整体赋值：lisi = {2,"lisi",80}; 非法
字符数组成员用 strcpy(lisi.name, "lisi");lisi.name = "lisi"; 非法（数组名是地址常量）
相互赋值同类结构体变量可直接赋值：zhangsan = lisi;把类型名当变量用
变量大小考试选理论值：各成员大小之和无说明时选对齐后的实际值

相关信息

scanf 取地址口诀

数值成员前加 &，字符数组名本身就是地址，不加 &：scanf("%d%s%f", &lisi.num, lisi.name, &lisi.score);

成员也可以是另一个结构体类型：嵌套成员一级级往下找，如 lisi.dahuang.age = 2;。

本课目标与前置回顾

学习目标

学完这节课，你能做到：

① 正确写出并区分 lisi.num、(*p).num、p->num，一眼判断 *p.num 为何非法；② 解释字符数组成员为何必须用 strcpy、结构体为何只能定义时整体初始化；③ 手写或补全结构体数组的选择排序（按某成员升序）；④ 说明 fopen 的 r/w/a 在打开失败时的不同行为，以及 fgetc/fputc 返回 EOF 的含义。

温故 · 第 12 课「指针进阶」：int(*p)[4] 与 int *p[4] 的本质区别是什么？

有括号时 (p) 先与 * 结合，p 是指针，即数组指针，指向含 4 个 int 的一行数组；无括号时 [] 优先级高，p 先与 [4] 结合，p 是数组，即含 4 个 int 指针的指针数组。

温故 · 第 11 课「指针基础与一维数组」：三种 swap 写法中，哪种能真正交换 main 里的变量？核心代码是什么？

传址并通过 x、y 直接修改实参值的版本：void swap(int *x, int *y){ int t=*x; *x=*y; *y=t; }。只传值的版本改的是副本，只交换形参指向的版本没改目标值，都不行。

相关信息

为什么这一课性价比高

结构体把「不同类型的数据捆成一个新类型」，文件把数据持久化到磁盘。这两章考点集中、题型固定，选择填空常考。巩固阶段的目标是：把易混写法记准，把代码模板写熟，直接对接刷题。

二、结构体数组与选择排序

struct Student stu[3] = {
    {1, "a", 80},
    {2, "b", 90},
    {3, "c", 70}
};

选择排序的核心：n 个数据执行 n-1 轮；每轮从未排序区找出最小值放到未排序区最前面；用变量 p 记录最小值的位置。

for (i = 0; i < n - 1; i++)
{
    p = i;
    for (j = i + 1; j < n; j++)
        if (stu[j].score < stu[p].score) p = j;
    if (p != i) { t = stu[i]; stu[i] = stu[p]; stu[p] = t; }
}

交换时用临时结构体变量整体交换，不要只交换某一个成员。

三、结构体指针：三种成员引用

struct Student lisi;
struct Student *p = &lisi;   /* 普通指针不能指向结构体变量 */

因为 . 和 -> 的优先级高于 *，所以 *p.num 会被理解为 *(p.num)，而 p.num 对指针非法。必须加括号或使用指向运算符。

写法含义是否等价于 lisi.num
lisi.num结构体变量名.成员是
(*p).num先解引用，再用点号是
p->num指向运算符，最简形式是
*p.num等价 *(p.num)，非法否

指针也可指向结构体数组：p = stu; 后 *p 即 stu[0]，*(p+1) 与 stu[1] 等价，可 p++ 逐个遍历。

四、文件：fopen / fgetc / fputc

FILE *fp;
fp = fopen("data.txt", "r");
if (fp == NULL) { /* 打开失败处理 */ }
打开方式含义打开失败时
r只读，从文件读数据返回 NULL
w只写，向文件写数据新建文件
a追加，向文件末尾添加数据文件不存在则新建（不因此失败）
函数调用方式功能失败/结束
fgetcfgetc(fp);从文件读一个字符返回 EOF
fputcfputc(ch, fp);向文件写一个字符返回 EOF

五、先回忆，再自测

合上笔记默写：访问结构体成员的三种正确写法，以及 *p.num 为何是错的

三种写法：lisi.num、(*p).num、p->num。因为 . 和 -> 优先级高于 ，p.num 会被解析为 *(p.num)，而 p.num 对指针不合法，所以必须写成 (*p).num 或 p->num。

结构体变量初始化的两条硬规则是什么？字符数组成员为什么不能直接赋值？

只能在定义变量的同时整体初始化，且常量顺序与成员顺序一致；先定义再整体赋值不合法。字符数组成员是数组名，属于地址常量，不能出现在赋值号左边，必须用 strcpy。

选择排序的轮数、p 变量的作用，以及 fopen 的 r/w/a 打开失败时分别怎样？

n 个数据执行 n-1 轮；p 记录未排序区最小值的位置。r 方式文件不存在时失败返回 NULL；w、a 方式文件不存在时都会新建文件。

六、测验（点击选项作答）

1. 已知 struct Student *p = &lisi;，下列成员引用写法错误的是

  • A. lisi.num（变量点成员）
  • B. (*p).num（解引用括号）
  • C. p->num（指向运算符）
  • D. *p.num（缺少括号）
点开核对答案

答案：D（*p.num（缺少括号）） —— . 和 -> 优先级高于 *，*p.num 等价于 *(p.num)，对指针 p 来说 p.num 非法；正确写法是 (*p).num 或 p->num。

2. 关于结构体变量的初始化，说法正确的是

  • A. 定义后再用{}整体赋值
  • B. 只能在定义变量时初始化
  • C. 结构体成员处直接赋初值
  • D. 对结构体类型名整体初始化
点开核对答案

答案：B（只能在定义变量时初始化） —— 结构体变量只能在定义的同时整体初始化，常量顺序与成员一致；先定义后整体赋值、对类型名赋值、在成员处初始化都不合法。

3. 对结构体中的 char name[20] 成员，正确赋值方式是

  • A. s.name = "Tom"（直接赋值）
  • B. strcpy(s.name,"Tom")（字符串拷贝）
  • C. s.name == "Tom"（关系比较）
  • D. name = "Tom"（缺结构体变量）
点开核对答案

答案：B（strcpy(s.name,"Tom")（字符串拷贝）） —— name 是数组名，属于地址常量，不能出现在赋值号左边；必须用 strcpy 把字符串拷贝到数组中。

4. 结构体数组按成绩升序进行选择排序，内层循环结束后 p 保存的是

  • A. 未排序区域中的最大值位置
  • B. 未排序区域中的最小值位置
  • C. 已排序区域中的首元素位置
  • D. 当前轮起始位置 i 的值
点开核对答案

答案：B（未排序区域中的最小值位置） —— 选择排序每轮从未排序区找最小值放到未排序区最前面，p 记录的就是这个最小值的位置。

5. fopen("data.txt", "r") 打开一个不存在的文件，结果是

  • A. 自动新建空白文件
  • B. 打开失败返回 NULL
  • C. 返回文件结束标志 EOF
  • D. 程序异常终止报错
点开核对答案

答案：B（打开失败返回 NULL） —— r 方式只读，文件不存在时返回 NULL；w、a 方式文件不存在时都会新建文件并成功打开（w 清空重写、a 保留后追加）。

6. 关于 fgetc 与 fputc，说法正确的是

  • A. 均以字符串为单位读写
  • B. 失败或结束时返回 NULL
  • C. 均以单个字符为单位读写
  • D. 只能用于二进制文件读写
点开核对答案

答案：C（均以单个字符为单位读写） —— fgetc 从文件读一个字符，fputc 向文件写一个字符；失败或文件结束返回 EOF，不是 NULL。

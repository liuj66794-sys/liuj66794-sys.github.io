能从具体循环得到次数表达式，并解释复杂度忽略什么。

先数执行次数，再谈增长速度

这一节要学会：能从具体循环得到次数表达式，并解释复杂度忽略什么。

做一份名单的检查，人数翻倍后工作量怎样变化？复杂度讨论的是输入规模增大时的增长趋势，不是某台电脑上的实际秒数。

先选基本操作，例如循环体的一次加法，再计数。顺序执行的两段工作次数相加；嵌套循环不能只看有几层，必须看每层实际上走几次。

下面内层次数依次为 1、2、3……n，总数是 n(n+1)/2。它的主导项是 n²，渐进量级为 Θ(n²)，也可给出 O(n²) 上界。常数和低阶项不改变这一量级，但会影响小输入的实际用时。

查看完整过程，逐步核对

第 1 步

for(i=1;i<=n;i++) for(j=1;j<=i;j++) count++; /* n=4 */

count 初值：0

每个外层 i 对应 i 次内层执行。

第 2 步

i=1：内层执行 1 次

本轮：1；累计：1

j 只取 1。

第 3 步

i=2：内层执行 2 次

本轮：2；累计：3

j 取 1、2。

第 4 步

i=3：内层执行 3 次

本轮：3；累计：6

不是每轮都执行 n 次。

第 5 步

i=4：内层执行 4 次

本轮：4；累计：10

一般化得到 1+2+…+n=n(n+1)/2。

核对判断与理由

两个顺序执行的 n 次循环，总体量级是？

  1. O(n)：对。次数相加是 2n，仍线性增长。
  2. O(n²)：只有适当的嵌套才会相乘，顺序执行相加。
  3. O(1)：次数随 n 增长，不是常数。

正确判断：O(n)

换个例子，自己试一次

先独立写出过程，再核对理由。遇到卡点可以回上一小节重走。

for(i=1;i<n;i*=2) 的循环体执行次数怎样增长？假设数值范围足够且 n 为正整数。

卡住时看提示

直接列出小于 16 的 1、2、4……；条件为 i<n，不包含等于 n 的那次。

查看参考过程

i 依次为 1、2、4、8……，经过 k 次更新约为 2^k。到达 n 需要约 log₂n 次，所以量级为 O(log n)。n=8 时循环体在 i=1、2、4 执行，共 3 次。

核对判断与理由

n=16 时上题循环体执行几次？

  1. 16：i 每次翻倍，不是加 1。
  2. 8：逐次列出 1、2、4、8 即可避免猜测。
  3. 4：对。i 到 16 时条件 i<n 已为假。

正确判断：4

一、五个必须精确的概念

包含关系（由大到小）：数据 > 数据对象 > 数据元素 > 数据项。

概念一句话定位例子
数据能输入计算机并被处理的符号集合全体学生档案
数据对象性质相同的数据元素的集合某班全体学生
数据元素数据的基本单位，整体处理一位学生
数据项构成数据元素的不可分割的最小单位学号、姓名
数据类型值的集合 + 操作的集合int、struct Student

易错

高频陷阱

说「数据元素是数据的最小单位」是错的；最小单位是数据项，数据元素只是基本单位。

本课目标与前置回顾

学习目标

学完这节课，你能做到：

① 快速区分数据、数据元素、数据项、数据对象四层包含关系，并指出最小单位；② 判断任一结构属于线性还是非线性，并说出四种存储结构；③ 默写算法五特性，能把常见循环嵌套化简为正确的大 O。

温故 · 第 13 课「结构体与文件」：访问结构体成员的三种正确写法是什么？*p.num 为什么错误？

三种写法：lisi.num、(*p).num、p->num。因为 . 和 -> 优先级高于 ，p.num 会被解析为 *(p.num)，而 p.num 对指针不合法。

温故 · 第 12 课「指针进阶」：char *s = "hello"; 合法，为什么 char s[10]; s = "hello"; 却非法？

char *s = "hello" 是声明时初始化，指针 s 接收字符串首地址，合法；而 s 是数组名，属于地址常量，不能出现在赋值号左边，应使用 strcpy(s, "hello")。

你已经用 C 语言把指针、结构体、文件都过了一遍，现在回头看绪论，所有抽象概念都能立刻落到代码实体上。这一章选择题、填空题密集，也是后面线性表、树、图的总纲。

二、数据结构的三要素

研究数据结构就是研究 逻辑结构、存储结构、数据的运算 这三方面。

逻辑结构：数据元素之间的逻辑关系，独立于计算机，与怎么存无关。分为：

  • 线性结构：线性表、栈、队列（串、数组/广义表也归此类）
  • 非线性结构：集合、树、图

存储结构（物理结构）：逻辑结构在计算机中的具体实现，依赖具体计算机语言。四种必须背熟：

  1. 顺序存储
  2. 链式存储
  3. 索引存储
  4. 散列存储

相关信息

一句话记忆

逻辑结构回答「元素之间是什么关系」；存储结构回答「在内存里怎么放、关系怎么表示」。

三、算法五特性与好算法目标

算法是解决问题的指令的有限序列。五个特性缺一不可：

特性含义
有穷性有穷步结束，每步有穷时间完成
确定性相同输入必有相同输出
可行性可通过已实现的基本运算执行有限次完成
输入零个或多个
输出一个或多个

易错

易混点

正确性、可读性、健壮性、高效率（时间/空间复杂度）是好算法的目标，不是算法本身的特性。判断题说「可读性是算法的重要特性」要判错。

四、时间复杂度的分析与化简

语句频度：某条语句被重复执行的次数。把所有语句频度之和记为 T(n)，则 T(n) = O(f(n))，其中 f(n) 取深层循环内基本运算的频度，只保留其数量级。

化简三规则：

  1. 常数项统一写成 1（如 T=3 → O(1)）。
  2. 只保留最高阶项（如 T=n²+n+3 → O(n²)）。
  3. 忽略系数与对数底数（如 T=5log₂n+15 → O(log n)）。

常见结论：一层遍历通常是 O(n)，两层嵌套且都与 n 有关通常是 O(n²)。例如：

for(i=1; i<=n; i++)
    for(j=1; j<=n; j++)
        printf("hello");

内层执行 n 次，外层执行 n 次，共 n² 次输出，时间复杂度为 O(n²)。

注意：时间复杂度还可能同时与问题规模 n 和待处理数据的初始状态有关——如直接插入排序，数据基本有序（最好）时为 O(n)，完全逆序（最坏）时为 O(n²)。

五、先回忆，再自测

正文未展开的一个考点：ADT（抽象数据类型）用（数据对象，数据关系，基本操作集）三元组表示（见笔记 10），描述数据的逻辑结构和抽象运算。

合上笔记：数据、数据对象、数据元素、数据项的包含关系？最小单位是？

包含关系：数据 > 数据对象 > 数据元素 > 数据项。最小单位是数据项；数据元素只是基本单位。

逻辑结构分哪两类？存储结构有哪四种？

逻辑结构：线性结构（线性表、栈、队列）和非线性结构（集合、树、图）。存储结构：顺序、链式、索引、散列。

算法五特性是什么？「可读性」算特性吗？

有穷性、确定性、可行性、输入、输出。可读性属于好算法目标，不是算法特性。

ADT 三元组是什么？

ADT（抽象数据类型）=（数据对象，数据关系，基本操作集）三元组，描述数据的逻辑结构和抽象运算。

六、测验（点击选项作答）

1. 在数据结构中，构成数据元素的不可分割的最小单位是

  • A. 数据对象
  • B. 数据项
  • C. 数据元素
  • D. 数据类型
点开核对答案

答案：B（数据项） —— 数据项是最小单位；数据元素是基本单位，数据对象是性质相同的数据元素的集合。

2. 下列关于逻辑结构的说法，正确的是

  • A. 它等同于存储结构
  • B. 它依赖于具体编程语言
  • C. 它回答元素在内存中如何存放
  • D. 它独立于计算机和实现
点开核对答案

答案：D（它独立于计算机和实现） —— 逻辑结构只描述元素之间的逻辑关系，与存储无关、独立于计算机；存储结构才依赖具体计算机语言。

3. 下列结构中，属于线性结构的是

  • A. 队列
  • B. 树
  • C. 图
  • D. 集合
点开核对答案

答案：A（队列） —— 线性结构包括线性表、栈、队列等；树、图、集合均属于非线性结构。

4. 下列不属于算法五个重要特性的是

  • A. 有穷性
  • B. 确定性
  • C. 可读性
  • D. 可行性
点开核对答案

答案：C（可读性） —— 可读性是好算法目标之一；算法特性只有有穷性、确定性、可行性、输入、输出。

5. 以下循环嵌套的时间复杂度是（其中 n 为问题规模） for(i=1;i<=n;i++) for(j=1;j<=n;j++) x++;

  • A. O(1)
  • B. O(n)
  • C. O(log n)
  • D. O(n²)
点开核对答案

答案：D（O(n²)） —— 外层循环 n 次，每次内层循环也 n 次，基本运算 x++ 共执行 n² 次，化简为 O(n²)。

6. 抽象数据类型 ADT 通常用哪个三元组表示

  • A. （逻辑结构、存储结构、基本运算）
  • B. （数据对象、数据关系、基本操作集）
  • C. （数据、数据元素、数据项）
  • D. （输入、输出、处理步骤）
点开核对答案

答案：B（（数据对象、数据关系、基本操作集）） —— ADT =（数据对象，数据关系，基本操作集）；它描述数据的逻辑结构和抽象运算。

# 使命：掌握 Mattpocock Skills

## 为什么

作为独立开发者，日常需要在多个 AI 客户端之间切换（如 Kimi Code CLI、Cursor、Claude Code、Codex 等）。学习 Mattpocock Skills 是为了把这些客户端的提示词/工作流标准化，让 AI 在代码审查、方案设计、Bug 诊断、需求拆解等关键任务上输出更稳定、更高质量的结果，从而减少反复沟通的成本，提升个人开发效率。

## 成功标志

- 能在常用的 AI 客户端中正确调用任意一个 Mattpocock Skill。
- 能根据当前任务（Review、Debug、设计、写需求等）快速判断该用哪个 Skill。
- 能说出每个核心 Skill 的适用场景、输入要求和典型输出形式。
- 能基于 Matt 的设计思路，写出或改造适合自己的个人/团队 Skill。

## 约束条件

- 学习以本地已安装的 39 个 skills 为素材，不额外追求网络上的二次解读。
- 优先关注与独立开发者日常最相关的技能：代码审查、Bug 诊断、方案设计、需求拆解、实现、交接。
- 采用“先全面概览，再按需深入”的策略，不强迫一次性精通所有技能。

## 范围之外

- 不研究 Skill 安装/分发/CLI 工具本身的源码实现。
- 不深入 AI 模型训练或通用提示工程理论，只聚焦 Mattpocock Skills 本身的使用方法。
- 暂不考虑团队协作流程的制度化落地（未来可扩展）。

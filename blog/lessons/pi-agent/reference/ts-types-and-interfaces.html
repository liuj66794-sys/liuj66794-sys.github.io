TS 类型与接口

这页是"类型系统"的压缩精华：写工具、读 pi 源码时随手查。

基础类型

类型含义例子
string字符串"hello"
number数字42, 3.14
boolean布尔true, false
string[]字符串数组["a", "b"]
any关闭类型检查尽量少用，临时占位

interface：对象的形状合同

interface Package {
  receiver: string;
  phone: string;
  address: string;
}

一旦声明 const pkg: Package = {...}，缺字段或多字段都会在运行前被 TypeScript 拦下。

可选属性与 readonly

interface ToolV2 {
  name: string;
  category?: string;   // ? 可选：没有也行
  readonly id: string; // readonly：创建后不可修改
}

Record<string, T>：容器的形状

Record<string, Tool> 读作"键为字符串、值为 Tool 的对象"——它描述的是容器长什么样，不是"获取所有工具"这个动作。

Agent 工具骨架（背下来）

interface Tool {
  name: string;
  description: string;
  execute: (args: Record<string, any>) => string;
}

const toolRegistry: Record<string, Tool> = {
  calculator,
  greeter,
};

function runTool(name: string, args: Record<string, any>): string {
  const tool = toolRegistry[name];
  if (!tool) return `错误：找不到名为 "${name}" 的工具`;
  return tool.execute(args);
}
面试怎么考 "你怎么保证 Agent 调用工具时参数不报错？"——答案骨架：用 interface / schema 在编译期校验参数形状（运行时的第二层校验后续课程会补）。

# 专升本《计算机基础与程序设计》Resources

## Knowledge

- 本库笔记：`C语言/01-09`、`数据结构/10-18`（18 篇主题笔记）
  由 60 个课程 PDF（1924 页）逐份整理，含考点标注、易错点、自测题。**课程的第一手知识来源**，备课以它为准，不凭模型记忆。核对覆盖范围见 `pdf/覆盖报告.md`。
- 本库题库：`题库/`（4 份章节练习、复习题一二三、2024/2025 真题、约 90 问简答手册）
  课后练习与冲刺模拟的题目来源。真题卷用于全真模拟，不要提前拆散当例题讲掉。
- [Book: 谭浩强《C程序设计》](https://book.douban.com/subject/25943753/)
  笔记中「📖Pxx」页码的出处。Use for：补齐 C 语言缺口（文件高级操作、选择/数组/指针缺失课次）、查证笔记存疑处。
- [Book: 严蔚敏《数据结构（C 语言版）》](https://book.douban.com/subject/26915940/)
  国内专升本数据结构通用教材。Use for：补齐归并排序、基数排序、B 树、静态链表等课件未讲内容。
- [cppreference — C 语言参考](https://zh.cppreference.com/w/c)
  C 标准库与语法权威参考。Use for：printf/scanf 格式符、字符串函数、文件函数的行为细节。

## Wisdom (Communities)

- [广东省教育考试院](https://eea.gd.gov.cn/)
  考纲、报名时间、政策的唯一权威来源。Use for：确认考试范围与时间，一切以官方公告为准。
- 知乎 / 小红书「广东专升本」话题
  往届考生的经验帖（时间规划、志愿填报）。Use for：备考节奏参考；信息质量参差，仅作参考不作依据。

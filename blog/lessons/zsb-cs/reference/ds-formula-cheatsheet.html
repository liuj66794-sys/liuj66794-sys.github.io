一、绪论：算法特性与时间复杂度

条目内容
算法五特性有穷性、确定性、可行性、输入（零个或多个）、输出（一个或多个）
好算法目标（非特性）正确性、可读性、健壮性、高效率——判断题眼：「可读性是算法特性」✘
数据结构三要素逻辑结构、存储（物理）结构、数据的运算；存储结构四种：顺序、链式、索引、散列
复杂度化简三步常数→O(1)（T=3）；只留最高阶（n²+n+3→O(n²)，2n²+n+1→O(n²)）；忽略系数与对数底数（5log₂n+15→O(log n)）
双重循环套路外层 n 次 × 内层 n 次 → O(n²)；复杂度与问题规模 + 数据初态有关

二、线性表：移动次数与链表操作

操作移动次数平均
第 i 个位置插入（i 从 1 起）n−i+1 个后移插入 n/2、删除 (n−1)/2，均 O(n)
删除第 i 个元素n−i 个前移
按值查找最多 n 次平均比较 (n+1)/2
三种判空不带头结点 L==NULL；带头结点 L->next==NULL；循环单链表 L->next==L
插入（s 插到 p 后）：s->next = p->next;  p->next = s;      /* 先接后断，顺序不能反 */
删除（删 p 的后继 q）：q = p->next;  p->next = q->next;  free(q);

三、栈和队列：循环队列公式

公式表达式
队满【全考】(rear + 1) % MaxSize == front
队空front == rear
指针进 1front = (front + 1) % MaxSize；rear = (rear + 1) % MaxSize
元素个数(rear - front + MaxSize) % MaxSize
最大容量N−1（牺牲一个存储单元区分空/满）
顺序栈栈空 top == base；栈满 top - base >= size；入栈先判满再存值 top++，出栈先判空再 top--

四、数组、矩阵与广义表

条目公式 / 规则
一维数组地址LOC(a[i]) = LOC(a[0]) + i×L（L 为每元素字节数）
二维行优先LOC = 基地址 + (i×列数 + j)×L；int a[4][5] 的 a[2][3] 是第 2×5+3+1=14 个
二维列优先LOC = 基地址 + (j×行数 + i)×L；a[2][3] 是第 4×3+2+1=15 个
对称矩阵压缩只存下三角（含对角线）：n(n+1)/2 个单元
稀疏矩阵三元组（行、列、值）；稀疏因子 t/(m×n)；压缩后失去随机存取
广义表长度/深度长度 = 最外层元素个数；深度 = 括号最大层数（子表要展开；空表深度 1）
Head / TailHead = 第一个元素（可原子可子表）；Tail = 其余元素组成的表（一定是广义表，要加括号）

非空子串n(n+1)/2

六、树与二叉树：六条性质

#性质
1第 i 层至多 2^(i−1) 个结点
2深度为 k 的二叉树至多 2^k − 1 个结点
3n₀ = n₂ + 1（叶子数 = 度 2 结点数 + 1）
4完全二叉树编号：双亲 ⌊i/2⌋；左孩 2i、右孩 2i+1（≤n 才存在）；结点 i 在第 ⌊log₂i⌋+1 层
5n 个结点的完全二叉树深度 = ⌊log₂n⌋+1
6完全二叉树叶子数：n 为奇数 (n+1)/2；n 为偶数 n/2
链域n 个结点的二叉链表有 n+1 个空链域
赫夫曼树n 个叶子共 2n−1 个结点、无度 1 结点；WPL = Σ 权ᵢ × 路径长度ᵢ；编码左 0 右 1（前缀编码）

七、图

条目公式 / 规则
完全图无向 n(n−1)/2 条边；有向 n(n−1) 条弧
度数有向：度 = 入度 + 出度；出度和为 s → 所有顶点度数之和 = 2s
生成树边数 = n−1 且无环；边数 < n−1 必不连通，> n−1 必有环
邻接矩阵空间 O(n²)；无向图必对称、n 顶点 e 边有效元 2e 个；有向图行 = 出度、列 = 入度
遍历DFS 借助栈（不撞南墙不回头）；BFS 借助队列；序列都可能不唯一
最小生成树Prim 加点 / Kruskal 选边——只针对无向图，结果不能有环
最短路径Dijkstra 单源；Floyd 全对：D(A,B) = min(D(A,B), D(A,k)+D(k,B))
拓扑 / 关键路径拓扑排序选入度 0 顶点输出并删其出边；关键活动判据 e == l

八、查找

条目公式 / 规则
ASLASL = Σ PᵢCᵢ（等概率 Pᵢ = 1/n；Cᵢ 为比较次数）
顺序查找ASL成功 = (n+1)/2；顺序表、链表都适用
折半查找仅有序顺序表；mid=(low+high)/2 向下取整；判定树高 ⌊log₂n⌋+1；O(log₂n)
除留余数法H(key) = key % p，p 取 ≤ 表长 m 的质数
冲突处理线性探测 dᵢ=1,2,…,m−1；平方探测 1²,−1²,2²,−2²,…；拉链法适合频繁插删
装填因子α = n/m；α 越大冲突可能性越大
BST左 < 根 < 右；中序遍历得递增序列；删双孩子结点用左子树最大（或右子树最小）替换
AVL平衡因子 = 左高 − 右高 ∈ {−1, 0, 1}；RR 左旋、LL 右旋、LR/RL 两次旋转

九、排序对比（一）：插入类与交换类

算法最好最坏/平均空间稳定性初始状态敏感
直接插入O(n)O(n²)O(1)稳定是
折半插入—O(n²)（比较次数与初态无关）O(1)稳定仅比较无关
希尔O(n)平均 O(n^1.3)O(1)不稳定是
冒泡O(n)O(n²)O(1)稳定是
快速—平均 O(nlog₂n)O(log₂n) 递归栈不稳定是（有序时最坏）

十、排序对比（二）：选择、归并与基数

算法最好最坏/平均空间稳定性初始状态敏感
简单选择—O(n²)O(1)不稳定比较次数无关
堆排序—O(nlog₂n)O(1)不稳定否
归并—O(nlog₂n)O(n)稳定否
基数—O(d(n+r))O(r)稳定否
速记内容
稳定性口诀「冒插基归稳，选堆快希不稳」
冒泡趟数最好 1 趟比较 n−1 次即停；最坏 n−1 趟、第 i 趟比较 n−i 次
堆排序两步① 倒着从 ⌊n/2⌋ 建堆；② 堆顶与堆尾交换、规模减 1、再调整；升序用大顶堆

3.2 / 与 % 的规则【必考】

运算符规则例
/右侧不能为 0；两侧均为整数 → 只保留整数部分；有一侧是小数 → 结果为 double1/3=0，7/3=2，7/2.0=3.5

4. printf / scanf

格式字符作用示例
%d有符号十进制整数（正数不输出 +）printf("%d",-100) → -100
%md指定列宽 m（含负号）%5d 输出 100 → □□100
%ldlong 型整数—

%%输出一个 %printf("a=%%d",a) → a=%d
  • 列宽补空格：m 为正左补、m 为负右补；数据宽度 ≥ |m| 原样输出。

  • C 语言本身没有输入输出语句，I/O 靠 stdio.h 库函数。

4.2 scanf 输入匹配规则【必考易错】

格式串写法输入方法
%d%d用空格、回车或 Tab 分隔两个数
%d,%d逗号必须原样输入：10,20
a=%d普通字符原样输入：a=2
%c%c%c连续输入，切勿加空格/回车（空格回车本身会被接收）
%3d截取指定宽度：输入 12345 只取 123，剩余留给下一变量
  • 地址列表必须是变量的地址（&变量名），缺 & 无法正确输入。
  • double 必须用 %lf 输入（%f 对 double 无效）；C 不提供 %m.nf 形式的输入（选项直接排除）。
  • scanf("%c%d",&ch,&a) 输入 123 → ch='1'，a=23。

5. 控制结构

5.1 语法骨架

if (表达式) 语句1;              /* 单分支：表达式非 0 执行 */
else 语句2;                     /* 双分支：只能走其中一条  */

switch (表达式)                 /* 表达式只能是整型/字符型 */
{
    case 常量1: 语句组1; break; /* case 后是整型/字符型常量，值必须唯一 */
    default: 语句组n;
}

while (表达式) 语句;            /* 先判断后执行，最少 0 次 */

do 语句; while (表达式);        /* 先执行后判断，最少 1 次；分号必须有 */

for (表达式1; 表达式2; 表达式3) 语句;
/* e1 只执行一次；e2 循环体前判断，省略则恒真死循环；e3 循环体之后执行 */
  • if(x) ≡ if(x!=0)；if(!x) ≡ if(x==0)；if(a=b) 是赋值不是比较。
  • else 配对：else 总与它前面最近的且未配对的 if 配对，与缩进无关；花括号可改变配对。
  • 短路规则：&& 左边为假右边不算；|| 左边为真右边不算（右侧自增/自减/赋值不执行）。
  • (ch=getchar())!='\n' 的括号不可省（!= 优先级高于 =）。

5.2 switch 规则要点

  • switch 表达式只能是整型或字符型（不能实型）；case 后只能整型/字符型常量且值必须唯一（case 'a' 与 case 97 重复报错）。
  • case 是"入口"，break 是"出口"：语句组无 break → 继续执行下一个 case 的语句组＝case 穿透【必考】。
  • default 只能一个、位置不影响匹配（先匹配所有 case，都不中才走 default）；全不中且无 default → 执行 switch 的下一条语句。
  • 嵌套 switch：内层 break 只结束内层（就近原则）。

5.3 break 与 continue【常考】

breakcontinue
作用范围结束整个所属循环（嵌套时只结束所属层）只提前结束本次，循环不终止
for 中去向循环的下一条语句（不经过表达式 3）表达式 3 → 再判表达式 2
可用位置switch + 循环仅循环体中

while / do-while 的 continue 直接回到条件表达式。循环体内 switch 的 break 只跳出 switch、不跳出循环。

运算符优先级规则例
~2（单目）按位取反（符号位也变）；规律 ~x = -x-1~3 = -4；~-3 = 2
<<5左移右侧补 0：m<<n = m×2ⁿ6<<1=12，6<<2=24
>>5右移：正数左补 0，负数左补 1；m>>n = m÷2ⁿ6>>1=3，-16>>2=-4

7. 数组与字符串

7.1 一维 / 二维数组规则

  • 定义：类型 数组名[常量表达式];，下标从 0 开始；int a[n]（变量）不合法、int a[2.3] 不合法；定义后大小不可改变。
  • 初始化：部分初始化其余自动为 0；int a[5]={0} 全零；int a[]={…} 省略长度按个数定；不指定长度又不初始化 → 报错；列表个数 > 长度 → 警告。
  • 数组名 = 首元素地址 = &a[0]，是地址常量：a++、a=a+1 非法；a+i ≡ &a[i]；a+1 实际加 sizeof(元素类型) 字节。
  • 引用只能逐个元素；下标越界不报错不警告，输出随机值。
  • 二维 int a[M][N]：内存线性连续存储；a[i][j] 之前有 i×N+j 个元素（是第 i×N+j+1 个）；初始化只能省第一维（行数），列数不可省；主对角线 i==j，副对角线 i+j==N-1。
  • 冒泡排序：n 个数比 n-1 趟，第 x 趟比 n-x-1 次；选择排序：n 个数据 n-1 轮。

7.2 字符数组与字符串

  • C 没有字符串类型，用字符数组或字符指针存放；处理字符串遇 '\0' 停止。
  • char c[]="abc" 长度 4（含 '\0'）；char c[5]={'a','b','c'} 长度 5、c[3]=c[4]='\0'。
  • scanf("%s",c) 参数 2 不能写 &c（数组名即地址）；%s 遇空格停，要收空格用 gets。

7.3 六大字符串处理函数

函数头文件形式功能与考点
putsstdio.hputs(字符数组)输出字符串，输出后自动换行；只能一个参数
getsstdio.hgets(字符数组)输入字符串，空格也收入；只能一个参数
strcatstring.hstrcat(数组1, 串2)连接：串 2 接到串 1 后（从串 1 的 '\0' 处接），数组 1 要足够大
strcpystring.hstrcpy(数组1, 串2)复制串 2（含 '\0'）进数组 1，数组 1 要足够大；解决数组名不能整体赋值（s="qwe" ✗）的问题
strcmpstring.hstrcmp(串1, 串2)按 ASCII 逐字符比较：大返回正数、相等 0、小负数；字符串不能用关系运算符比较
strlenstring.hstrlen(串)测长度不含 '\0'（遇 '\0' 停）；strlen("abc\0def")=3

strlen vs sizeof：strlen 测字符串长度（不含 '\0'）；sizeof 求占内存字节数（含 '\0'）——问"占几个字节"用 sizeof。

8. 指针

8.1 基础规则

  • 指针就是地址；指针变量是存放地址的变量；基类型必须一致（int 指针不能指 float 变量）。
  • 指针变量只能赋地址（或 0/NULL 表示零号地址），赋整型常量非法；& 后只能跟变量、* 后只能跟地址。
  • p+1 实际加 sizeof(基类型) 字节；同数组内 p2-p1 = 元素个数差；指针相加/乘/除无意义。
  • 指针变量同字长下大小一样：32 位机 4 字节、64 位机 8 字节。

8.2 核心等价关系（必背）

一维：a ≡ &a[0]，a+i ≡ &a[i]，*(a+i) ≡ a[i]，*(p+i) ≡ p[i]（p 先指 a[0]）。

表达式（二维）含义
a二维数组名（首行地址 &a[0]）
a+i / &a[i]第 i 行的地址
*(a+i) / a[i]第 i 行首元素地址 &a[i][0]
*(a+i)+j / a[i]+ji 行 j 列元素的地址 &a[i][j]
*(*(a+i)+j) / *(a[i]+j)i 行 j 列元素的值 a[i][j]
*a / a[0]0 行 0 列元素地址 &a[0][0]

a 与 &a[0][0] 数值相同但类型不同：a 是指向一行的指针 int(*)[n]，a[0]、&a[0][0] 是 int*。

8.3 五种带 * 的定义辨析（必背）

定义含义属性
int (*p)[4]指向"含 4 个 int 的一行数组"指针变量（数组指针）
int *p[4]含 4 个元素，每个元素都是指针数组（指针数组）
int (*p)()指向函数的指针（不能做 p+1 运算）指针变量（函数指针）
int *p()返回值是地址（指针）的函数函数
int **p指向指针的指针（二级指针），**p 才是值指针变量

判断口诀：p 先与 [ ] 结合是数组，先与 ( ) 结合是函数。

8.4 传值 vs 传址【必考对比】

方式写法能否交换 main 的 a、b
传值swap(int x,int y)，调用 swap(a,b)失败——形参拿副本，改形参不影响实参
传址 + 交换值swap(int *x,int *y)，体内 t=*x; *x=*y; *y=t;成功
传址 + 只换指向体内 t=x; x=y; y=t;失败——只交换了形参指针的指向

数组名作实参＝传首元素地址（传址）：形参数组与实参数组共用内存，形参元素变了实参跟着变；形参数组名按指针处理（void f(int arr[],int n) 等价 void f(int *arr,int n)）。

字符串：char *s="hello"（声明初始化）合法；*s="hello"、s={"abcd"}（赋值语句）、char s[10]; s="abcd"; 均非法——数组名是常量，用 strcpy。

9. 函数

  • 先定义后使用；被调函数定义在下方时需在调用前声明：
int fun(int x, int y);   /* 写法一：带形参名 */
int fun(int, int);       /* 写法二：只写参数类型（形参名可省） */
  • return 规则：只能返回一个值；return(a,b); 返回逗号表达式的值（b）；执行到 return 函数即结束、其后代码不再执行；返回值类型与函数类型不一致时自动转换；void 函数名没有值。
  • 传值单向 vs 数组名传址：普通实参传值（单向赋值，形参变实参不变）；数组名作实参传首地址（形参数组变、实参数组跟着变）；形参数组大小 = 指针大小（4/8 字节）；二维形参可省第一维、不可省第二维（int a[][3]）。
  • static 静态局部变量四要点【必考】：① 整个运行期间不释放（调用结束值保留）；② 编译时赋初值、只赋一次；③ 不赋初值自动为 0（数值型）或 '\0'（字符型）；④ 调用结束后仍存在，但只能被本函数引用。
  • 全局变量不初始化默认 0（局部自动变量才是随机值）；与局部变量同名时函数内局部屏蔽全局；作用域 = 定义处到源文件结束。
  • 存储类别：auto（默认，动态存储区）、register（CPU 寄存器）、static（静态存储区）、extern（声明扩展全局变量作用域，不分配空间、不可再初始化）。
  • 函数间平行不能嵌套定义；函数未调用不占内存（形参也不占）。递归必须有终止条件、逐层返回（f(n)=f(n-1)*n，f(1)=1 → 5!=120）。

10. 结构体与文件

10.1 结构体

struct Student          /* struct 是关键字 */
{
    int num;
    char name[20];
    float score;
};                      /* ← 这个分号不能少 */
  • 成员只能定义变量：不可直接初始化、不可出现常量；"类型"不可赋值不可初始化。
  • 类型不占空间，定义变量才开辟；变量大小 = 各成员之和（考试无特别说明选理论值，如 4+20+4=28 字节）。
  • 只能在定义变量的同时整体初始化（常量次序与成员一致）；先定义再 lisi={…} 非法，只能逐成员赋值。
  • 字符数组成员必须用 strcpy：lisi.name="lisi"; ✗ → strcpy(lisi.name,"lisi"); ✓（name 是地址常量）。
  • scanf 时数值成员加 &、数组名成员不加：scanf("%d%s%f",&lisi.num,lisi.name,&lisi.score);
  • 同类结构体变量可相互赋值：zhangsan = lisi;
三种成员访问（p 指向 lisi 时等价）【易考】
lisi.num(*p).num（必须加括号）p->num（指向运算符）

*p.num 非法——≡ *(p.num)，因 . 和 -> 优先级高于 *。

10.2 文件

fopen 打开方式含义打开失败时
r只读，从文件读数据返回 NULL

fputcfputc(字符, 文件指针);向文件写一个字符返回 EOF
FILE *fp;
fp = fopen("a.txt", "r");        /* 打开失败返回 NULL，先判空再用 */
char c;
while ((c = fgetc(fp)) != EOF)   /* 常用循环写法 */
    putchar(c);

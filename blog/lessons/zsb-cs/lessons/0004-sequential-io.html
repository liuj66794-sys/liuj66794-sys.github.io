把输入、格式串、目标变量对齐

这一节要学会：能判断 scanf 成功写了几个变量，并正确检查输入失败。

scanf 像按清单收货：格式串列出预期的数据种类，地址告诉它放进哪个格子。printf 是取出值给人看，因此同一个变量在输入和输出时传入的东西可能不同。

int a,b; scanf("%d %d", &a, &b) 尝试转换两个整数。&a、&b 提供可写入的地址。返回值表示成功完成的赋值数；只有返回 2 时，才能按“两个整数都读到了”继续处理。

%d 等转换会跳过前导空白；%c 通常不跳过。" %c" 前面的空白指令会消耗输入空白，再读取一个字符。实际写程序还需核对类型：scanf 的 %f 对应 float*，%lf 对应 double*。

查看完整过程，逐步核对

第 1 步

int a=0, b=0; 输入缓冲内容：12 x

a：0；b：0

先给变量确定的初值，方便观察失败时哪些值没改。

第 2 步

第一个 %d 匹配 12

a：12；b：0

第一个转换成功，将 12 写入 a。

第 3 步

第二个 %d 遇到 x

a：12；b：0；返回值：1

x 不能转换为整数，第二次赋值没有发生。

第 4 步

if (scanf("%d %d", &a, &b) == 2) { /* 两个输入有效 */ }

进入成功分支：否

这是本次读取的检查形式，不是再读一遍。示例返回 1，所以应进入错误处理。

核对判断与理由

读取两个整数时 scanf 返回 1，说明？

  1. 两个变量都有效：返回 2 才能证明两个转换都完成。
  2. 只成功赋值一个变量：对。返回值统计成功赋值次数，不是输入数值。
  3. 输入的第一个数是 1：返回值不是输入内容本身。

正确判断：只成功赋值一个变量

换个例子，自己试一次

先独立写出过程，再核对理由。遇到卡点可以回上一小节重走。

输入 "7 8" 给 int a,b;，写出读取和成功时输出和的两行核心代码。

卡住时看提示

把两个 %d 与两个 int 的地址一一配对，再检查成功赋值次数是否等于 2。

查看参考过程

if (scanf("%d %d", &a, &b) == 2) { printf("%d\n", a+b); }。输入传地址，输出传计算得到的整数值；失败分支应报告或重新处理输入。

核对判断与理由

scanf("%d", ...) 为 int n 读取数据，应该传？

  1. n：n 是已有的整数值，不能代替目标地址。
  2. &n：对。&n 指向要写入的 int 对象。
  3. *n：n 不是指针，不能在这里解引用。

正确判断：&n

一、printf 格式输出

printf 的格式是 printf(格式控制字符串, 输出列表);。格式控制串里分为两类内容：

  • 普通字符：原样输出，例如 printf("a=%d", 100); 中的 a=。
  • 格式声明符：% 开头，对应输出列表中的一项；有几个格式符就应有几项，缺项会输出随机值，多余项不输出。
格式符含义高频示例
%d有符号十进制整数printf("%d", 100); → 100
%md / %-md指定列宽；正数右对齐、负数左对齐%5d 输出 100 → □□100
%f实型，默认 6 位小数printf("%f", 1/2.0); → 0.500000
%m.nf宽度 m，保留 n 位小数（四舍五入）%6.3f 输出 -3.1415 → -3.142（"-3.142" 本身 6 字符，宽度 6 恰好装满，不补空格；%7.3f 才得 □-3.142）
%.nf只保留 n 位小数%.2f 输出 3.1415 → 3.14
%c单个字符（不带单引号）printf("%c", 97); → a
%s字符串（不带双引号）printf("%s", "hi"); → hi
%o / %x八进制 / 十六进制，不带前缀、不带符号%#o / %#x 才带 0 / 0x 前缀
%e指数形式，默认 6 位小数123.456 → 1.234560e+02
%%输出一个 %printf("%%"); → %；陷阱：printf("a=%%d,b=%%d",a,c); 输出 a=%d,b=%d，参数 a、c 不输出
%u无符号十进制2 字节 unsigned a = -1 → 65535

⚠️ 列宽与四舍五入规则

%m.nf 的 m 是总宽度，小数点、负号都算进宽度；n 位小数按四舍五入。规则：m 为正左补空格，m 为负右补空格，数据实际宽度 ≥ |m| 时原样输出。

例如 printf("%8.2f", -100.125);：先四舍五入为 -100.13，总宽度 8，当前占 7 位，所以左补一个空格 → □-100.13；而 %-9.2f 则左对齐 → -100.13□□。

C 语句分类速记：五种语句——表达式语句、函数调用语句、控制语句、复合语句、空语句。复合语句整体算一条语句，最后一个 } 后不加分号；#include、#define 是预处理指令，不是语句。

本课目标与前置回顾

学完这节课，你能做到：

① 给定 printf 格式串和输出项，能写出屏幕上的实际结果（含 %m.nf 列宽、四舍五入与对齐）；② 看到 scanf 格式串，能判断用户应该怎么输入（普通字符、%c、%lf 等陷阱）；③ 正确使用 putchar / getchar 处理单字符输入输出。

温故 · 第 3 课「运算符与表达式」：a=10 时，表达式 a += a -= a*a 的结果是多少？
赋值右结合：先算 a -= a*a，得 a = 10 − 100 = −90；再算 a += (−90)，得 a = −180。
温故 · 第 2 课「数据的表示：数制、补码与常量」：十进制转成非十进制，整数和小数部分分别怎么做？175 的二进制、八进制、十六进制各是什么？
整数部分「除 N 取余，倒序输出」；小数部分「乘 N 取整，正序输出」。175 = 10101111B = 257Q = AFH。

为什么这节课关键

printf / scanf 是广东专升本程序阅读题和选择题的最大题源之一，尤其是 %m.nf 输出、double 必须用 %lf、%c 会吃空格、格式串中普通字符要原样输入——这四点每年必考。

二、scanf 格式输入

scanf 的格式是 scanf(格式控制字符串, 地址列表);，地址列表必须是 &变量名。scanf 是给变量赋值，必须知道变量地址，没有 & 数据存不进去。

格式串写法正确输入方式常见错误
%d%d用空格、回车或 Tab 分隔，如 10 20用逗号分隔
%d,%d逗号必须原样输入，如 10,20输入 10 20
a=%d普通字符原样输入，如 a=2只输 2
%c%c%c连续输入 3 个字符，如 abc输入 a b c，空格会被当字符读入
%c,%c,%cq,w,e，逗号也要输入用空格替代逗号
%3d输入 12345 只取 123，剩余留给下一个变量以为会读完整数

⚠️ scanf 两大硬规则

  • double 必须 %lf： double x; scanf("%f", &x); 无法正确输入；必须用 %lf。printf 输出时 float / double 都可以用 %f。
  • C 没有 %m.nf 形式的输入： 形如 scanf("%5.2f", &x); 的写法直接判错。
  • %c 会吃空格 / 回车： scanf("%c%d", &ch, &a); 输入 123，ch 得到 '1'，a 得到 23。

三、putchar 与 getchar

  • int putchar(int ch);：输出单个字符，参数可以是字符常量、字符变量、ASCII 码或转义符。例如 putchar('A'); → A；在 ASCII 编码环境下，putchar(97); → a。
  • int getchar(void);：从键盘缓冲区读一个字符；按回车后才从 stdin 逐个读取，多余字符留在缓冲区，等待后续 getchar 读取。

小应用：大写转小写

大写字母 ASCII +32 即得小写。教材例题：c2 = c1 + 32; 或直接把 getchar() + 32 传给 putchar() / printf("%c", ...)。

四、先回忆，再自测

合上笔记回答：printf("%8.2f", -100.125); 输出什么？□ 代表空格。
先四舍五入为 -100.13，总宽度 8，当前 7 位，左补一个空格 → □-100.13。
合上笔记回答：char ch; int a; scanf("%c%d", &ch, &a); 输入 123 后，ch 和 a 分别是？
ch = '1'，a = 23。%c 只读一个字符，剩下的 "23" 按 %d 解析。
合上笔记回答：double x; 用 scanf 输入时格式符应该写什么？
必须用 %lf：scanf("%lf", &x);。%f 无法正确读入 double。
合上笔记回答：C 语句分哪五种？复合语句末尾要加分号吗？
表达式语句、函数调用语句、控制语句、复合语句、空语句。复合语句整体算一条语句，最后的 } 后不加分号；#define 等预处理指令不是语句。

五、测验（点击选项作答）

1. 执行 printf("%6.2f", -3.1415);，输出结果是

  1. 输出 -3.14
  2. 输出 □-3.14
  3. 输出 -3.142
  4. 输出 □-3.142

%6.2f 保留 2 位小数，-3.1415 四舍五入为 -3.14；总宽度 6，当前 5 位，左补一个空格 → □-3.14。

2. 关于 scanf 的输入规则，正确的是

  1. double 变量可用 %f 正确输入
  2. 格式串中的逗号必须原样输入
  3. %c 会自动跳过空格再读取字符
  4. scanf 支持 %5.2f 这种输入格式

double 必须 %lf；%c 会接收空格；C 不提供 %m.nf 输入。普通字符（如逗号）必须按格式串原样输入。

3. 执行 char c; scanf("%c", &c);，输入 5（先空格后 5）后，c 的值是

  1. 字符 '5'
  2. 字符 ' '
  3. 整数 5
  4. 随机字符

%c 读取单个字符，不会跳过空格，第一个输入的字符就是空格，所以 c = ' '。

4. 在 ASCII 编码环境下，执行 putchar(97);，屏幕输出是

  1. 输出字符 a
  2. 输出字符 9
  3. 输出整数 97
  4. 输出字符串 "97"

putchar 输出单个字符；在 ASCII 编码环境下，97 是 'a' 的编码值，所以输出 a。

5. 执行 printf("%-6.2f", 3.1415);，输出结果是

  1. 输出 □□3.14
  2. 输出 3.14□□
  3. 输出 3.1415
  4. 输出 3.142□

负号表示左对齐；保留 2 位小数后 3.14 占 4 位，宽度 6，右侧补两个空格 → 3.14□□。

6. 执行 double x; scanf("%lf", &x);，输入 1.5 后，x 的值是

  1. 1
  2. 1.5
  3. 1.05
  4. 不确定

double 用 %lf 输入能正确接收，x 的值就是 1.5；1.05 无从得出——%.1f、%.2f 这类格式符只在输出显示时四舍五入，不改变变量的存储值。

循环队列里的下标会绕回起点

这一节要学会：能按约定判断空满，并计算入队、出队后的长度。

循环队列像环形停车位：车辆按到达顺序出场，下标走到末尾会绕回 0。先进先出描述次序，数组首尾位置只是存储方法。

本例采用“front 指向队头，rear 指向下次入队位置，留一个空位判满”的约定。容量为 M 的数组最多保存 M-1 个元素；空为 front==rear，满为 (rear+1)%M==front。其他约定会有不同公式。

入队先检查未满，写到 rear 后再更新 rear；出队先检查非空，取 front 后再更新 front。长度为 (rear-front+M)%M。栈则后进先出，不能套队列的出队顺序。

查看完整过程，逐步核对

第 1 步

初始化 front=0, rear=0

队列：空；长度：0

四个数组位置，按本约定最多存三个元素。

第 2 步

依次入队 A、B、C

front：0；rear：3；逻辑队列：A B C

(3+1)%4=0，与 front 相等，已满。

第 3 步

出队 A：front=(front+1)%4

front：1；rear：3；逻辑队列：B C

空出原来的位置 0；位置 3 可用于下次入队。

第 4 步

入队 D 到下标 3；rear=(3+1)%4

front：1；rear：0；逻辑队列：B C D

rear 绕回 0；长度 (0-1+4)%4=3。

核对判断与理由

最后 rear<front，说明队列长度为负吗？

  1. 是：下标绕回不等于逻辑长度为负。
  2. 否，应按取模公式计算：对。取模把跨数组末尾的情况统一处理。
  3. 说明队列为空：空的条件是两者相等，不是大小关系。

正确判断：否，应按取模公式计算

换个例子，自己试一次

先独立写出过程，再核对理由。遇到卡点可以回上一小节重走。

同一约定 M=5，front=3，rear=1。队列长度多少？下一次出队后 front 变多少？

卡住时看提示

先从位置 3 沿环走到 rear=1，数经过的有效位置；出队只移动 front。

查看参考过程

长度 (1-3+5)%5=3；出队后 front=(3+1)%5=4。原来三个元素所在位置按顺序为 3、4、0。

核对判断与理由

若把 A、B、C 依次压入栈，再弹出一次，得到？

  1. A：A 是先进先出的队列结果。
  2. B：B 还被 C 压在下面。
  3. C：对。栈后进先出，C 最后压入先弹出。

正确判断：C

一、栈与队列的核心对比

栈 Stack队列 Queue
原则后进先出 LIFO先进先出 FIFO
插入位置栈顶队尾 rear
删除位置栈顶队头 front
逻辑结构都是线性表（运算与存储实现可不同）

最高频陷阱

栈只在栈顶插删，队列只在队尾入、队头出。出现「删除栈底元素」「在队头插入」的选项直接判错。

本课目标与前置回顾

学完这节课，你能做到：

① 说出栈 LIFO 与队列 FIFO 的插删位置，不被「栈底出栈」这类陷阱带偏；② 用模拟法判断任意出栈序列是否合法；③ 默写循环队列四公式，并解释为何要牺牲一个单元；④ 把中缀表达式转成后缀（逆波兰式）；⑤ 写对链队列的判空条件。

温故 · 第 15 课「线性表」：顺序表在第 i 个位置插入、删除第 i 个元素分别要移动多少个元素？平均移动次数呢？
插入第 i 个位置要 n-i+1 个元素后移，删除第 i 个元素要 n-i 个元素前移；插入平均移动 n/2 次，删除平均移动 (n-1)/2 次，时间复杂度均为 O(n)。
温故 · 第 14 课「数据结构绪论与时间复杂度」：算法的五个特性是什么？「可读性」算算法特性吗？
有穷性、确定性、可行性、输入、输出，五个特性缺一不可；可读性是好算法的目标，不是算法本身的特性，判断题说「可读性是算法的重要特性」要判错。

为什么现在要巩固这个

栈和队列是数据结构里「操作受限的线性表」，广东专升本年年考：循环队列四公式、出栈序列合法性、中缀转后缀。你一节课把它们焊死，后面图和排序会轻松很多。

二、顺序栈：top 指向栈顶元素的下一个单元

状态 / 操作条件或公式
栈空top == base
栈满top - base >= size
入栈 Push先判满，值送入 *top，再 top++
出栈 Pop先判空，top--，再取 *top

链栈用单链表头部作栈顶，最大优点：不存在栈满上溢，空间按需增长。

三、循环队列：四公式与牺牲一个单元

普通顺序队列会出现「假溢出」——rear 走到数组尾，但前面已出队的位置空着。把数组首尾相连成环就是循环队列。

含义公式
队满(rear + 1) % MaxSize == front
队空front == rear
队首指针进 1front = (front + 1) % MaxSize
队尾指针进 1rear = (rear + 1) % MaxSize
元素个数(rear - front + MaxSize) % MaxSize

为什么要牺牲一个单元

空队和满队都满足 front == rear，无法区分。所以约定「牺牲一个存储单元」：rear 再往前走一步等于 front 时视为满。因此大小为 N 的数组，循环队列最多存 N - 1 个元素。

四、中缀 → 后缀（逆波兰式）

表达式形式运算符位置示例 a + b
中缀操作数中间a + b
前缀（波兰式）操作数之前+ a b
后缀（逆波兰式）操作数之后a b +

转换/求值借助栈。例如 a * (b + c) - d 的后缀式为 abc+*d-：先算括号内 bc+，再与 a 相乘 abc+*，最后减 d 得 abc+*d-。

五、链队列

链队列是带 front 和 rear 两个指针的单链表。注意：

  • 判空：front == NULL（课件原文「Q->front==NULL 且 Q->front==NULL」后半应为 rear，系笔误）。
  • 不存在队满溢出问题，适合数据元素变动较大的情形。

六、先回忆，再自测

合上笔记默写：循环队列四公式与最大容量
队满 (rear+1)%MaxSize==front；队空 front==rear；指针进 1 用 (x+1)%MaxSize；元素个数 (rear-front+MaxSize)%MaxSize。大小为 N 的数组最多存 N-1 个元素（牺牲一格区分空满）。
入栈序列 a,b,c,d，判断出栈序列 c,b,d,a 是否合法，并写出推理
合法。模拟：a 入、b 入、c 入，c 出；栈顶为 b，b 出；d 入，d 出；a 出。每一步栈顶都等于目标序列当前元素，所以合法。
中缀式 a*(b+c)-d 转成后缀式的步骤是什么
先处理括号内 b+c 得 bc+；再与 a 相乘得 abc+*；最后减 d 得 abc+*d-。

七、测验（点击选项作答）

1. 下列关于栈的描述，正确的是

  1. 栈底元素最先进栈也最先出栈
  2. 栈顶元素最后进栈却最先出栈
  3. 栈允许在栈底进行删除操作
  4. 栈的插入和删除可在任意端进行

栈按后进先出 LIFO 原则，只在栈顶插删。栈顶元素最后进、最先出；栈底最先进、最后出。

2. 入栈序列 1,2,3,4，下列不可能是出栈序列的是

  1. 1 2 3 4
  2. 4 3 2 1
  3. 1 3 2 4
  4. 4 1 2 3

若 4 第一个出栈，说明 1–4 已全部入栈，此时栈顶是 3，下一位只能是 3 而非 1。模拟法可知 D 不合法。

3. 大小为 6 的循环队列，初始 rear=0、front=3，删除 1 个元素再加入 2 个元素后，rear 和 front 分别是

  1. rear=0，front=4
  2. rear=1，front=4
  3. rear=2，front=4
  4. rear=4，front=2

删除 1 个：front=(3+1)%6=4；加入 2 个：rear 从 0 依次变为 (0+1)%6=1、(1+1)%6=2。注意 rear 指向队尾元素的下一个位置。

4. 用大小为 N 的数组实现循环队列，采用牺牲一个单元区分空满，该队列最多可存储的元素个数是

  1. N - 1
  2. N
  3. N + 1
  4. 2N

牺牲一个单元后，队满条件为 (rear+1)%MaxSize==front，因此实际可用空间为 N-1。

5. 中缀表达式 a*(b+c)-d 对应的后缀表达式是

  1. a b c + * d
  2. a b c + * d -
  3. * a + b c - d
  4. a * b + c - d

后缀式中运算符在操作数之后。先算 b+c 得 bc+，再乘 a 得 abc+*，最后减 d 得 abc+*d-。

6. 关于链队列，下列说法正确的是

  1. 判空条件是 rear == NULL
  2. 存在队满溢出问题
  3. rear 指向队尾元素的下一个位置
  4. 适合数据元素变动较大的情形

链队列判空看 front==NULL；不存在队满；rear 指向最后一个结点本身；正因动态分配，适合元素变动大的场景。

7. 容量 70 的循环队列，front=20、rear=11，当前元素个数为

  1. 11
  2. 20
  3. 61
  4. 70

元素个数公式为 (rear-front+MaxSize)%MaxSize。代入 (11-20+70)%70 = 61。

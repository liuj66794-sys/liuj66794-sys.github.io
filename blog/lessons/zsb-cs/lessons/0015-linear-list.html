链表插入为什么先接后面

这一节要学会：能解释指针修改顺序，并区分找节点与修改连接的代价。

单链表像每张卡片只记着下一张的地址。要在 A 和 B 之间插入 X，必须先让 X 记住 B，再让 A 指向 X；否则原来的后半段入口可能丢失。

设 p 指向 A，s 指向已分配好的 X。s->next=p->next 保存原来的后继；p->next=s 才把新节点接入主链。这里假定指针有效、节点已成功分配，不把分配失败藏起来。

“链表插入 O(1)”通常指已经知道前驱后的连接修改。若还要从头按位置找到前驱，寻找成本是 O(n)。顺序表能按下标直接访问，但中间插入通常要移动后续元素。

查看完整过程，逐步核对

第 1 步

起点：p 指向 A，s 指向 X

A.next：B；X.next：尚未设置；B.next：NULL

A → B → NULL

主链是 A→B→NULL；X 还不在主链中。

第 2 步

s->next = p->next;

A.next：B；X.next：B

X → B；A → B

先保存旧后继。此时主链仍可沿 A 到达 B。

第 3 步

p->next = s;

A.next：X；X.next：B

A → X → B → NULL

再把 A 的后继改成 X。

核对判断与理由

如果先 p->next=s，再 s->next=p->next，会怎样？

  1. 仍然正确：第二句读到的已不是原来的 B。
  2. X.next 指向 X 自己：对。此时 p->next 已经是 s，所以把 X 接回自己。
  3. B 自动接到 X 后面：链表不会自动修复丢失的连接。

正确判断：X.next 指向 X 自己

换个例子，自己试一次

先独立写出过程，再核对理由。遇到卡点可以回上一小节重走。

已知 p 的后继 q 需要删除且 q 非空，写出保留后链并释放 q 的核心步骤。

卡住时看提示

在释放目标结点前，先取出它的后继并让前驱接过去。

查看参考过程

先 q=p->next；再 p->next=q->next；最后 free(q)。前提是 q 来自可用 free 释放的分配，且后续不再访问 q。头结点与首元结点的约定需先看题目。

核对判断与理由

为什么不能先 free(q)，再读取 q->next？

  1. 释放后 q->next 仍保证可读：释放的对象已不再可供访问。
  2. 释放后再访问对象属于无效访问：对。应在释放前完成需要的连接读取。
  3. free 会自动保存后继：free 不负责维护链表逻辑。

正确判断：释放后再访问对象属于无效访问

一、线性表的本质：逻辑结构

线性表是相同数据类型的 n(n≥0) 个数据元素的有限序列，记作 L=(a₁, a₂, …, aₙ)。除第一个元素外，每个元素有且仅有一个直接前驱；除最后一个元素外，每个元素有且仅有一个直接后继。

概念分层

⚠️ 线性表是逻辑结构，描述的是元素之间一对一的相邻关系；顺序表和链表才是存储结构。考题如果说「线性表是顺序存储结构」就是错的。

本课目标与前置回顾

学完这节课，你能做到：

① 脱口说出顺序表插入/删除的移动次数公式与平均移动次数；② 按值查找平均比较 (n+1)/2；③ 闭眼默写单链表插删两行代码与双链表插入四行；④ 区分三种链表的判空条件；⑤ 根据「频繁插删」或「频繁按位访问」选择存储方式。

温故 · 第 14 课「数据结构绪论与时间复杂度」：逻辑结构分为哪两类？存储结构有哪四种？
逻辑结构分为线性结构（线性表、栈、队列）和非线性结构（集合、树、图）；存储结构包括顺序存储、链式存储、索引存储、散列存储四种。
温故 · 第 13 课「结构体与文件」：fopen 以 r、w、a 三种方式打开文件失败时，分别会发生什么？
r 只读方式失败返回 NULL；w 只写方式失败会新建文件；a 追加方式失败返回 NULL。

为什么这节课很重要

线性表是数据结构的开篇，后面栈、队列、串、树都要反复用到「顺序存储 vs 链式存储」的思维。插删移动次数、单链表两行代码、三种判空条件，是专升本填空与选择题的必考点。这节课帮你把公式和代码钉进长期记忆。

二、顺序表：随机存取快，插删要搬家

顺序表用一组地址连续的存储单元依次存放元素，逻辑相邻 ⟺ 物理相邻。三大特点：① 随机访问 O(1)；② 存储密度高；③ 插入删除要移动元素。

操作最好最坏第 i 个位置平均移动次数复杂度
插入0（表尾）n（表头）n-i+1 个元素后移n/2O(n)
删除0（表尾）n-1（表头）n-i 个元素前移(n-1)/2O(n)
按值查找1 次n 次—(n+1)/2 次O(n)

记忆诀窍

插入要腾位置，所以比删除多移 1 个：插入 n-i+1，删除 n-i。插入有 n+1 个可插位置，所以平均 n/2；删除只有 n 个元素可删，所以平均 (n-1)/2。按值查找平均比较 (n+1)/2 次，三者都答 O(n)。

三、单链表：指针接力，先接后断

链表用一组任意的存储单元存放元素，靠指针建立逻辑关系。结点 = 数据域 + 指针域。它不能随机存取，查找必须从表头遍历；但插入删除只需改指针。

3.1 判空条件

循环链表：尾结点 next 指回头结点（不指 NULL）形成环，因此从表中任意结点出发都能扫描整个表。

带头结点的循环单链表，判空条件为 L->next == L。

链表类型判空条件
不带头结点L == NULL
带头结点L->next == NULL
循环单链表L->next == L

3.2 核心代码

单链表插入：把 s 插到 p 之后，口诀「先接后断」。

s->next = p->next;    /* 先接：s 接管 p 的后继 */
p->next = s;          /* 后断：p 指向 s；两句顺序不能反 */

单链表删除：删除 p 的后继结点。

q = p->next;          /* q 指向被删结点 */
p->next = q->next;    /* 绕过被删结点 */
free(q);              /* 释放空间 */

四、双链表：插入四句，先解决后继再解决前驱

双链表结点有 prev 和 next 两个指针，找前驱不用从头遍历。把 s 插入 p 之后：

s->next = p->next;      /* ① s 接管后继 */
p->next->prev = s;      /* ② 后继回指 s */
s->prev = p;            /* ③ s 回指 p */
p->next = s;            /* ④ p 指向 s */

教材勘误

⚠️ 课件原稿此处印作 p->next-prev，漏写了 ->prev 中的箭头，实际应为 p->next->prev = s，请以教材为准。

五、按场景选存储结构

对比项顺序表链表
存取方式可顺序、可随机存取只能顺序存取
插入删除移动元素，O(n)只改指针，O(1)（定位后）
空间静态分配，易溢出/浪费动态分配，按需申请
适用场景频繁按位访问、取前驱频繁插入删除、长度变化大

六、先回忆，再自测

合上笔记默写：顺序表插入、删除的移动次数公式，以及平均移动次数和按值查找平均比较次数
插入第 i 个位置：n-i+1 个元素后移；删除第 i 个元素：n-i 个元素前移。插入平均移动 n/2，删除平均移动 (n-1)/2，按值查找平均比较 (n+1)/2 次，三者时间复杂度均为 O(n)。
合上笔记默写：单链表插入、删除的两行/三行代码；双链表插入的四行顺序
单链表插入：s->next=p->next; p->next=s;（顺序不能反）。单链表删除：q=p->next; p->next=q->next; free(q)。双链表插入：s->next=p->next; p->next->prev=s; s->prev=p; p->next=s。
三种链表判空条件分别是什么？频繁插入删除该选顺序表还是链表？
不带头结点：L==NULL；带头结点：L->next==NULL；循环单链表：L->next==L。频繁插入删除选链表；频繁按位访问或取前驱选顺序表。

七、测验（点击选项作答）

1. 长度为 20 的顺序表，在第 5 个位置插入新元素，需要移动的元素个数为

  1. 14 个元素后移
  2. 16 个元素后移
  3. 15 个元素后移
  4. 17 个元素后移

顺序表插入第 i 个位置需移动 n-i+1 个元素：20-5+1=16。注意是「后移」为第 i 个位置腾出空间，不要与删除的 n-i 混淆。

2. 关于顺序表的平均移动次数，下列说法正确的是

  1. 插入 n/2 次，删除 n/2 次
  2. 插入 (n-1)/2 次，删除 n/2 次
  3. 插入 n/2 次，删除 (n-1)/2 次
  4. 插入 (n+1)/2 次，删除 n/2 次

插入有 n+1 个可插入位置，平均 n/2；删除有 n 个元素可删，平均 (n-1)/2。按值查找平均比较 (n+1)/2 次，不要套用到移动次数上。

3. 单链表中，将结点 s 插入到 p 之后，正确的两句代码是

  1. p->next=s; s->next=p->next;
  2. s->next=p->next; p->next=s;
  3. s->next=p; p->next=s->next;
  4. p->next=s->next; s->next=p;

口诀「先接后断」：先把 s 的 next 指向 p 原来的后继，再让 p 指向 s。若先执行 p->next=s，则第二句 s->next 会指向 s 自己，造成断链。

4. 双链表中，将结点 s 插入到 p 之后，四句的正确顺序是

  1. s->next=p->next; s->prev=p; p->next=s; p->next->prev=s;
  2. s->next=p->next; p->next->prev=s; s->prev=p; p->next=s;
  3. p->next=s; s->prev=p; s->next=p->next; p->next->prev=s;
  4. s->prev=p; p->next=s; s->next=p->next; p->next->prev=s;

口诀「先解决后继结点，再解决前驱结点」：s 接管后继 → 后继回指 s → s 回指 p → p 指向 s。若先改 p->next，后面再用 p->next->prev 就会访问到 s 而非原后继。

5. 下列关于链表判空条件的说法，正确的是

  1. 带头结点的链表判空为 L==NULL
  2. 循环单链表判空为 L->next==NULL
  3. 不带头结点的链表判空为 L->next==NULL
  4. 循环单链表判空为 L->next==L

不带头结点：L==NULL；带头结点：L->next==NULL；循环单链表：L->next==L（尾结点 next 回指头结点，形成环）。

6. 某应用需要频繁对线性表进行插入和删除，且表长变化较大，宜采用的存储结构是

  1. 顺序表，因其可随机存取
  2. 链表，因其插删只改指针
  3. 顺序表，因其存储密度较高
  4. 链表，因其支持随机存取

频繁插入删除选链表，定位后修改指针即可 O(1)；顺序表插删需移动大量元素。链表不能随机存取，必须顺序遍历，因此 D 错。

遍历的区别在于何时访问根

这一节要学会：能在同一棵树上对照先序、中序、后序，而不是换题就重背。

把每个结点看成一间带左右房间的屋子。先序是在进门时登记，中序是在左屋回来后登记，后序是在左右都回来后登记；走的递归结构相同，记录时机不同。

先序是根→左→右，中序是左→根→右，后序是左→右→根。这里的“左”指整棵左子树，不是只看一个左孩子。层序则按层逐个访问，通常使用队列。

下面固定树 A(B(D,E),C)，展示中序访问。试着每到一个结点先问：左子树处理完了吗？处理完才能写下这个结点。

树：A 的左孩子是 B、右孩子是 C；B 的左孩子是 D、右孩子是 E。

查看完整过程，逐步核对

第 1 步

从 A 向左到 B，再向左到 D

输出：空

当前：D

到达不等于访问；A、B 都在等待左子树。

第 2 步

D 无左子树，访问 D

输出：D

返回：B

D 是叶子，随后返回 B。

第 3 步

访问 B，再进入 B 的右子树 E

输出：D B

当前：E

B 的左子树完成，现在才登记 B。

第 4 步

访问 E，再返回 A 并访问 A

输出：D B E A

当前：A

整棵 B 子树完成，A 才能被登记。

第 5 步

进入并访问 A 的右子树 C

输出：D B E A C

结束

完成中序遍历。

核对判断与理由

这棵树的先序第一个结点是谁？

  1. D：D 是中序起点，但先序先访问根。
  2. A：对。先序先登记整棵树的根 A。
  3. B：在先序中需要先登记 A，才进入左子树 B。

正确判断：A

换个例子，自己试一次

先独立写出过程，再核对理由。遇到卡点可以回上一小节重走。

仍用 A(B(D,E),C)，独立写出后序和层序。

卡住时看提示

后序把 A 放最后，并先完整处理 B 子树；层序先写 A，再写 B、C。

查看参考过程

后序：D E B C A；层序：A B C D E。后序先完成左右子树，最后登记 A；层序把孩子依次放入队列，先处理较早入队的结点。

核对判断与理由

只给一个先序序列且结点互异，一般能唯一还原二叉树吗？

  1. 能，根已确定：确定根不等于确定所有连接。
  2. 不能，左右子树分界还不确定：对。常用互异结点的先序加中序来确定各子树边界。
  3. 一定是完全二叉树：一个遍历序列不保证完全二叉树形状。

正确判断：不能，左右子树分界还不确定

一、四种遍历的口诀

遍历口诀次序
先（前）序根左右先访问根，再递归左子树，最后右子树
中序左根右最左叶子起：左子树→根→右子树
后序左右根左→右→根
层次从上到下、从左至右借助队列，逐层访问

中序小技巧

中序不好下手时，可用「补齐法」把缺的孩子补成空、补成满二叉树辅助，再按「左根右」走一遍，不容易漏结点。

本课目标与前置回顾

学完这节课，你能做到：

① 脱口背出四种遍历口诀：先序根左右、中序左根右、后序左右根、层次从上到下、从左至右；② 对任意二叉树手写先序、中序、后序序列，并用文字描述「借助队列」的层次遍历步骤；③ 用「先序/后序定根、中序分左右」完整还原一棵二叉树并写出第三种遍历序列；④ 判断哪些序列组合能唯一还原——先序+中序、后序+中序可以，只有先序+后序不行。

温故 · 第 19 课「树与二叉树基础」：二叉树的叶子数 n₀ 与度为 2 的结点数 n₂ 有什么关系？
n₀ = n₂ + 1，即叶子数等于度为 2 的结点数加 1；例如有 10 个度为 2 的结点，叶子就有 11 个。
温故 · 第 18 课「串」：空串和空格串是一回事吗？
不是。空串长度为 0，一个字符都没有；空格串由一个或多个空格组成，长度等于空格的个数。

为什么现在复习遍历

遍历是二叉树大题的「发动机」：给两个序列求第三个序列、还原二叉树、画树形图，卷面上反复出现。这节课专注 §2.3 遍历与还原这一块，把口诀、示例树、两道完整推演一次讲透。

二、层次遍历：借助队列的四个步骤

  1. 根结点入队；
  2. 队头结点出队并访问；
  3. 把出队结点的左、右孩子依次入队（存在才入）；
  4. 重复 2–3，循环至队空。

记住辅助结构是队列——先进先出才能保证「从上到下、从左至右」的次序。

三、课件示例树：三种序列各走一遍

用文字把这棵树搭出来：根为 1；1 的左孩子是 2、右孩子是 3；2 没有左孩子，右孩子是 4；4 的左孩子是 7、右孩子是 8；3 的左孩子是 5、右孩子是 6。

        1
      /   \
     2     3
      \   / \
       4 5   6
      / \
     7   8

按「整棵树 = 根 + 左子树序列 + 右子树序列」的递归思路拆：

  • 先序（根左右）：1 + (2,4,7,8) + (3,5,6) = 1,2,4,7,8,3,5,6
  • 中序（左根右）：(2,7,4,8) + 1 + (5,3,6) = 2,7,4,8,1,5,3,6
  • 后序（左右根）：(7,8,4,2) + (5,6,3) + 1 = 7,8,4,2,5,6,3,1

课件勘误（以树形为准）

① 课件中序印作「2,7,4,8,1,3,6」——漏了结点 5，按树形更正为 2,7,4,8,1,5,3,6；② 课件后序那一页的前缀误写为「中序遍历」，内容实为后序序列 7,8,4,2,5,6,3,1。背序列时认树形，别认印刷。

四、还原二叉树：定根 + 分左右

还原规则一句话：先序/后序定根，中序分左右。

  • 先序序列的第一个字符是根；后序序列的最后一个字符是根；
  • 到中序序列里找到这个根：它左边全是左子树的结点，右边全是右子树的结点；
  • 对左、右子树各取对应的先序/中序片段，递归做下去，整棵树就画出来了。

因此：先序+中序 或 后序+中序 可以唯一还原一棵二叉树。

易错点

只给先序+后序不能唯一还原——两个序列都只负责「报根」，没有中序就没人负责「分左右」，子树边界划不开。必须有中序。

五、完整还原推演两例

5.1 例一（随堂练习 4）：先序 EFHIGJK、中序 HFIEJGK，求根的右子树的根

  1. 先序第一个字符 E = 整棵树的根；
  2. 在中序 HFIEJGK 中找到 E：左边 HFI 是左子树，右边 JGK 是右子树；
  3. 右子树的先序片段是 GJK，第一个字符 G = 右子树的根。答案 C. G。

顺手把左子树也定掉：左子树先序 FHI、中序 HFI → 左子树根是 F。

5.2 例二（随堂练习 11）：先序 ABCDEF、中序 CBAEDF，求后序

  1. 先序第一个 A = 根；中序 CBAEDF 中 A 左边 C B 是左子树、右边 E D F 是右子树；
  2. 左子树：先序 B C、中序 C B → 根 B，C 在 B 左边 → C 是 B 的左孩子；左子树后序 = C B；
  3. 右子树：先序 D E F、中序 E D F → 根 D，E 在左、F 在右；右子树后序 = E F D；
  4. 整树后序 = 左后序 + 右后序 + 根 = C B + E F D + A = CBEFDA。答案 A。

六、先回忆，再自测

四种遍历的口诀分别是什么？层次遍历借助什么结构？
先序根左右、中序左根右、后序左右根；层次遍历从上到下、从左至右，借助队列（根入队→出队访问→左右孩子依次入队→循环至队空）。
还原二叉树的规则？哪两种组合可以唯一还原？
先序/后序定根，中序分左右子树。先序+中序、后序+中序可唯一还原；只给先序+后序不能——必须有中序才能分左右。
为什么只给先序+后序不能唯一还原二叉树？
先序和后序只能确定根（先序第一个、后序最后一个），分左右必须靠中序中根的位置；没有中序，子树边界划不开，答案不唯一。
课件示例树的三种遍历序列分别是什么？两处勘误还记得吗？
先序 1,2,4,7,8,3,5,6；中序 2,7,4,8,1,5,3,6（课件漏印结点 5）；后序 7,8,4,2,5,6,3,1（课件该页前缀误写「中序遍历」）。

七、测验（点击选项作答）

1. 中序遍历的口诀是

  1. 根左右
  2. 左右根
  3. 从上到下从左至右
  4. 左根右

中序左根右；根左右是先序，左右根是后序，从上到下从左至右是层次遍历。四个口诀要能对应无误。

2. 层次遍历二叉树需要借助的辅助结构是

  1. 栈
  2. 散列表
  3. 二维数组
  4. 队列

层次遍历借助队列：根入队→出队访问→左右孩子依次入队→循环至队空，先进先出保证逐层次序。

3. 课件示例树（根 1，2 的右孩子 4，4 的孩子 7、8，3 的孩子 5、6）的后序序列为

  1. 1,2,4,7,8,3,5,6
  2. 2,7,4,8,1,5,3,6
  3. 7,8,4,2,5,6,3,1
  4. 7,4,8,2,6,5,3,1

后序左右根：(7,8,4,2)+(5,6,3)+1 = 7,8,4,2,5,6,3,1。A 是先序、B 是中序；注意课件该页前缀误写「中序遍历」，内容实为后序。

4.（随堂练习 4）先序 EFHIGJK、中序 HFIEJGK，根的右子树的根是

  1. E
  2. F
  3. G
  4. K

先序定根 E；中序中 E 右边的 JGK 是右子树，右子树先序片段 GJK 的第一个字符 G 即右子树的根。左子树根为 F。

5.（随堂练习 11）先序 ABCDEF、中序 CBAEDF，后序序列为

  1. CBEFDA
  2. CBAEDF
  3. ABCDEF
  4. FEDCBA

根 A，左子树 {B,C}（B 根、C 左孩子）后序 CB，右子树 {D,E,F}（D 根，E 左 F 右）后序 EFD，整树后序 CB+EFD+A = CBEFDA。B 是中序、C 是先序本身。

6. 只给先序和后序两个遍历序列，能否唯一还原一棵二叉树？

  1. 能，先序定根后序定尾就够了
  2. 不能，但加上层次遍历序列也无法还原
  3. 不能，必须有中序才能分左右子树
  4. 不能，必须有层次遍历序列

先序+后序只能「定根」，分左右必须靠中序中根的位置，所以不能唯一还原。可唯一还原的组合是先序+中序、后序+中序。

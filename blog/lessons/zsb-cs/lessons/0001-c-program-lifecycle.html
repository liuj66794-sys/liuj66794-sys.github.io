从源代码到运行结果

这一节要学会：能根据现象定位出错阶段，而不是把所有错误都叫作编译错误。

把程序想成一道菜：源代码是食谱，编译器把食谱翻译成机器能处理的指令，链接器把用到的各部分拼到一起，运行才是真正开始做菜。食谱写完不代表菜已经做好。

以 C 程序为例，预处理处理 #include 等指令，编译与汇编产生目标文件，链接把目标文件和所需库组合成可执行文件。教学中常把预处理、编译、汇编统称为“编译阶段”；判断题要先看题目采用哪种粒度。

printf 的声明让编译器知道怎样检查调用；函数实现仍需在链接时解决。语法正确只表示程序通过了相应检查，不能保证计算逻辑正确。下面按“已有文件→进行操作→得到什么”逐步看。

查看完整过程，逐步核对

第 1 步

#include <stdio.h>
int main(void) { printf("%d\n", 2 + 3); return 0; }

当前材料：main.c

编辑阶段保存的是文本，还没有执行加法。

第 2 步

预处理 → 编译 → 汇编

输入：main.c；产物：目标文件

检查并翻译源程序。不同工具链可能使用 .o 或 .obj 扩展名。

第 3 步

目标文件 + 所需库 → 链接

产物：可执行文件

组合代码，解析外部符号；缺少函数实现通常在这里暴露。

第 4 步

启动可执行文件

屏幕输出：5

此时程序才实际运行。若写成 2-3，仍可能成功构建，只是结果不符合原意。

核对判断与理由

程序已成功生成可执行文件，但把求和写成求差。主要属于？

  1. 语法错误：求差的语法本身合法，不能只靠语法检查发现意图错误。
  2. 逻辑错误：对。机器执行了写下来的运算，但它偏离了任务要求。
  3. 缺少函数实现：缺少实现通常阻止链接成功；这里已经能运行。

正确判断：逻辑错误

  1. 是，构建通过就是正确：构建检查不能代替需求和边界验证。

  3. 只要能输出就正确：输出存在与输出正确是两件事。

正确判断：否，还要用样例和边界输入验证

一、四步骤与三个扩展名

C 程序的实现经过 编辑 → 编译 → 连接 → 运行 四步（注意：是四步，不是五步——题干把「执行」拆开数就是错的）：

步骤产物文件性质这一步做什么
编辑.c 源程序文本文件把源程序输入计算机存盘
编译.obj 目标程序二进制词法分析 + 语法分析，报错定位
连接.exe 可执行程序二进制把目标程序与库文件连接
运行运行结果—运行 .exe 得到结果

最高频陷阱

源程序（.c）和目标程序（.obj）都不能被计算机直接执行，只有 .exe 能。同理：能被计算机直接执行的语言只有机器语言；C 是高级语言，必须先编译。

本课目标与前置回顾

学完这节课，你能做到：

① 默写 C 程序从源代码到运行的四个步骤及每步产物的扩展名；② 一眼识破「谁能被计算机直接执行」这类陷阱题；③ 说清 main 函数的两条硬性规则和注释的编译行为。

为什么先学这个

编译四步骤是整套试卷填空、选择、简答都考过的最高频考点，也是理解后面「头文件 / 库函数 / 链接错误」等地基。你已经学过一轮——这节课用最快的速度把记忆重新钉牢。

二、配套的三组判断

C 的诞生：由 Denis M. Ritchie（丹尼斯·里奇）于 1972—1973 年在美国贝尔实验室设计（常考判断/选择）。

语言三代：机器语言 → 汇编语言 → 高级语言；机器 + 汇编统称低级语言（都依赖具体机器）。高级语言分两种翻译方式：解释（边翻译边执行，不产生目标程序）和编译（整体翻译成目标程序，再连接成可执行文件）——C 属于编译方式。

main 函数：有且只有一个，是程序的入口和出口；程序总是从 main 开始执行，与 main 写在什么位置无关。每个函数由函数头 + 函数体两部分组成，函数之间是平行关系，不能嵌套定义。

注释：// 到换行符结束、不能跨行；/* */ 可跨行。注释不参与编译，编译器不会发现注释里的任何错误。另外记住：C 本身没有输入/输出语句，I/O 靠 scanf/printf 库函数完成。

四、测验（点击选项作答）

1. 下列文件中，能被计算机直接执行的是

  1. 扩展名为 .c 的源程序文件
  2. 扩展名为 .obj 的目标文件
  3. 扩展名为 .exe 的可执行文件
  4. 扩展名为 .h 的头文件

只有可执行文件能直接运行；.c 是文本、.obj 是二进制目标文件，都要先经过后续步骤。

2. C 源程序经过「编译」这一步后得到的产物是

  1. 可直接运行的可执行文件
  2. 需再连接的目标程序
  3. 逐句翻译的解释结果
  4. 包含库函数的可执行程序

编译产生 .obj 目标程序，它不能单独执行，必须由连接程序与库文件连接成 .exe。

3. 关于 C 程序的执行起点，正确的是

  1. 总是从 main 函数开始执行
  2. 从最前面的函数开始执行
  3. 从最后面的函数开始执行
  4. 从预处理命令开始执行

与 main 的位置无关，程序永远从 main 开始；main 有且只有一个，是入口也是出口。

4. 关于注释，下列说法正确的是

  1. 单行注释可以跨越多行书写
  2. 编译器能发现注释中的错误
  3. 注释中的语句会被编译执行
  4. 块注释可以跨越多行书写

// 到换行符止，不能跨行；/* */ 可跨行。注释不参与编译。

5. 机器语言和汇编语言统称为

  1. 高级语言，不依赖具体机器
  2. 低级语言，依赖具体机器
  3. 符号语言，可移植性很好
  4. 自然语言，易学易读易修改

机器 + 汇编 = 低级语言，都依赖具体计算机，难学难用；汇编又称符号语言，但它仍属低级语言。

6. C 语言的输入/输出功能是依靠什么实现的

  1. 属于 C 语言关键字的输入输出命令
  2. 编译器自带的输入输出语句
  3. scanf 和 printf 等库函数
  4. 预处理命令提供的输入输出

C 本身没有 I/O 语句，靠库函数完成——这正是它移植性好的原因之一。

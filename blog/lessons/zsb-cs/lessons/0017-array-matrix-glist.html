二维地址公式就是先数前面有几个元素

这一节要学会：能由行列坐标推导偏移，并保留元素大小单位。

把电影院座位按行接成一条长队：先跳过前面的整行，再在当前行向右走。地址公式并不神秘，它只是“元素个数×每个元素大小”。

设数组 a[R][C] 从下标 0 开始，按行优先连续存储。a[i][j] 前面有 i 个完整行，每行 C 个元素，再加当前行的 j 个，故偏移元素数为 i*C+j。

若首元素地址为 B、每个元素占 w 字节，地址就是 B+(i*C+j)*w。题目若下标从 1 开始、列优先或矩阵压缩存储，要先调整模型，不能直接套同一公式。

查看完整过程，逐步核对

第 1 步

设 B=1000，w=4，a[3][4]

目标行：1；目标列：2

这些地址和元素大小是本例题设，不代表 int 在所有环境都固定 4 字节。

第 2 步

先跳过 1 个完整行

跳过元素：1×4=4

来到 a[1][0]，已跨 16 字节。

第 3 步

本行再走 2 个元素

总元素偏移：4+2=6

来到 a[1][2]。

第 4 步

1000 + 6×4

地址：1024

先数元素，再乘大小，避免漏乘 w。

核对判断与理由

同一题设下 a[2][0] 的地址是？

  1. 1008：这是把元素偏移直接当成字节偏移。
  2. 1032：对。2×4=8 个元素，跨 32 字节。
  3. 1024：这是演示中 a[1][2] 的地址。

正确判断：1032

换个例子，自己试一次

先独立写出过程，再核对理由。遇到卡点可以回上一小节重走。

按行优先压缩存储一个 n 阶下三角（含主对角线），下标从 0 开始。第 i 行之前存了多少元素？

卡住时看提示

第 2 行前面只有第 0、1 两行，压缩后分别占 1、2 个位置。

查看参考过程

前面的行长度分别为 1、2、…、i，总数 i(i+1)/2。因此合法的 0<=j<=i 位置 (i,j) 对应压缩下标 i(i+1)/2+j。不要把完整矩阵每行 n 个的模型照搬过来。

核对判断与理由

下三角压缩位置 (2,1) 的零起始下标是？

  1. 7：完整矩阵和压缩数组的行长度不同。
  2. 4：对。前两行 1+2=3 个，再加列偏移 1。
  3. 3：3 是这一行第一个元素的位置，还要加 j。

正确判断：4

一、数组地址计算：先定顺序，再数元素

数组元素占用一段连续空间，类型相同、大小固定，支持下标随机访问。对数组只能做两种基本操作：查找和修改，不能插入删除。

1.1 一维数组

设首地址为 LOC(a₀)，每个元素占 L 字节：

LOC(a[i]) = LOC(a[0]) + i × L

1.2 二维数组的两种存储顺序

以 int a[4][5]（4 行 5 列）为例：

存储方式地址公式a[2][3] 是第几个元素
行优先LOC = 基地址 + (i×列数 + j)×L2×5+3+1 = 14
列优先LOC = 基地址 + (j×行数 + i)×L4×3+2+1 = 15

易错点

列优先不是 j×列数，而是 j×行数——因为一列里要"沾满"行数个元素。口诀：先看沾满几行/列，每行/列几个元素，再加上它本身。

本课目标与前置回顾

学完这节课，你能做到：

① 手算一维/二维数组在行优先、列优先下的地址与元素序号；② 说出对称矩阵压缩所需单元数 n(n+1)/2 及稀疏矩阵三元组存储的代价；③ 正确求广义表的长度、深度（含空表深度 1）以及 GetHead/GetTail（表尾必须加括号）。

温故 · 第 16 课「栈和队列」：循环队列的队满、队空条件是什么？元素个数怎么求？大小为 N 的数组最多能存几个元素？
队满 (rear+1)%MaxSize==front，队空 front==rear，元素个数 (rear-front+MaxSize)%MaxSize；因为要牺牲一个存储单元区分空满，大小为 N 的数组最多存 N-1 个元素。
温故 · 第 15 课「线性表」：把结点 s 插到单链表中结点 p 之后，两句代码怎么写？顺序能反吗？
s->next=p->next; p->next=s;（口诀「先接后断」）。顺序不能反，若先执行 p->next=s，第二句 s->next 会指向 s 自己，造成断链。

为什么这节课值得再过一遍

数组地址计算、矩阵压缩、广义表 Head/Tail 是数据结构部分填空与选择的高频组合题，往往一道题连环考两三个概念。巩固阶段的关键不是"看懂"，而是能在一分钟内不出错地推导。

二、矩阵压缩：省空间，但失去随机存取

压缩存储：为多个值相同的元素只分配一个空间，对零元素不分配空间，目的是减少存储空间。

2.1 特殊矩阵

值相同或零元素分布有规律的矩阵：对称矩阵、上（下）三角矩阵、对角矩阵。

  • 对称矩阵：n 阶方阵满足 aᵢ,ⱼ = aⱼ,ᵢ，只需存下三角（含对角线），共需 n(n+1)/2 个存储单元。
  • 三角矩阵：下三角矩阵存下三角+对角线，上三角区为同一常量 c 时额外再存一个 c；上三角矩阵对称同理。

2.2 稀疏矩阵

  • 非零元素个数 t 相对于总数 m×n 非常少；稀疏因子 = t/(m×n)。
  • 用三元组（行标 i、列标 j、值 v）存储每个非零元素。
  • ⚠️ 压缩存储后失去随机存取特性——这是常考判断点。

辨析

数组是线性数据结构（连续存储、下标访问）；矩阵是数学概念（行列结构），计算机中用二维数组实现。所以"数组就是矩阵，矩阵就是数组"是错误的。

三、广义表：长度、深度、表头、表尾

广义表是表元素可以是原子或广义表的线性表的推广。

  • 长度 = 最外层元素个数。
  • 深度 = 括号最大层数，子表要展开后数。
  • 空表 A=()：长度 0，深度 1。
广义表长度深度说明
A = ()01空表
B = (d, e)21元素全是原子
C = (b, (c, d))22原子 b + 子表
D = (B, C)23展开后为 ((d,e),(b,(c,d)))
E = (a, E)2∞递归表

3.1 GetHead 与 GetTail

  • GetHead：取第一个元素，可以是原子或子表。
  • GetTail：去掉第一个元素后，剩余元素加括号组成的表——表尾一定是广义表。

例：D = ((a,(b,c)), (d,(e)))

  • GetHead(D) = (a,(b,c))
  • GetTail(D) = ((d,(e)))

高频错误

L=(a,(b,c)) 的表尾不是 (b,c)，而是 ((b,c))；((a,b,c,d)) 的表尾是空表 ()，因为外层只有一个元素，去掉后剩余为空。

四、先回忆，再自测

合上笔记默写：行优先与列优先地址公式，并说明 a[2][3] 在 int a[4][5] 中分别是第几个元素
行优先：LOC = 基地址 + (i×列数 + j)×L，a[2][3] 是第 2×5+3+1=14 个；列优先：LOC = 基地址 + (j×行数 + i)×L，a[2][3] 是第 4×3+2+1=15 个。列优先不是 j×列数，而是 j×行数。
默写：对称矩阵压缩单元数、稀疏矩阵存储结构与代价、空表深度
对称矩阵存下三角（含对角线），需 n(n+1)/2 个单元；稀疏矩阵用三元组 (i,j,v) 存储；压缩后失去随机存取特性；空表 () 的深度是 1，不是 0。
判断正误并说明：GetHead 一定是广义表；GetTail 一定是广义表
第一句错误，第二句正确。GetHead 取第一个元素，可以是原子或子表；GetTail 去掉第一个元素后其余元素加括号组成，必定是广义表。

五、测验（点击选项作答）

1. 对于 int a[4][5]，按行优先存储时 a[2][3] 是第几个元素

  1. 第 13 个元素
  2. 第 14 个元素
  3. 第 15 个元素
  4. 第 16 个元素

行优先公式：i×列数+j+1 = 2×5+3+1 = 14。列优先才是 4×3+2+1 = 15。

2. n 阶对称矩阵采用压缩存储，至少需要多少个存储单元

  1. n² 个存储单元
  2. n(n−1)/2 个单元
  3. n(n+1)/2 个单元
  4. (n+1)²/2 个单元

只存下三角（含对角线）：1+2+…+n = n(n+1)/2。

3. 稀疏矩阵用三元组存储后，下列说法正确的是

  1. 仍可直接随机存取
  2. 失去随机存取特性
  3. 访问速度明显更快
  4. 必须按行号顺序存取

三元组只记录非零元素的行、列、值，无法通过下标直接定位元素，因此失去随机存取特性。

4. 已知 B=(d,e)，C=(b,(c,d))，则 D=(B,C) 的深度为

  1. 1 层括号深度
  2. 2 层括号深度
  3. 3 层括号深度
  4. 4 层括号深度

求深度要把子表展开：D=((d,e),(b,(c,d)))，最内层 (c,d) 有 3 层括号，故深度为 3。

5. 广义表 L=(a,(b,c))，GetTail(L) 的结果是

  1. (b,c) 一个子表
  2. ((b,c)) 一个表
  3. b,c 两个原子
  4. c 单个原子

表尾是去掉第一个元素后其余元素加括号组成的表，因此是 ((b,c))，不是 (b,c)。

6. 关于空广义表 A=()，下列说法正确的是

  1. 长度为 0，深度为 0
  2. 长度为 0，深度为 1
  3. 长度为 1，深度为 0
  4. 长度为 1，深度为 1

空表最外层元素个数为 0，故长度为 0；但它本身是一对括号构成的表，深度为 1。

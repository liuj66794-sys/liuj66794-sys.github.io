积分公式与凑微分速查表

📄 建议打印随身 与 速查 003 求导表 逐条互逆 来源：笔记《不定积分》§二–§八

① 基本积分公式表

公式公式
$\int k\,dx=kx+C$$\int x^{\mu}dx=\dfrac{x^{\mu+1}}{\mu+1}+C\ (\mu\neq-1)$
$\int\dfrac{dx}{x}=\ln|x|+C$$\int\dfrac{dx}{\sqrt x}=2\sqrt x+C$；$\int\dfrac{dx}{x^{2}}=-\dfrac1x+C$
$\int e^{x}dx=e^{x}+C$$\int a^{x}dx=\dfrac{a^{x}}{\ln a}+C$
$\int\sin x\,dx=-\cos x+C$$\int\cos x\,dx=\sin x+C$
$\int\sec^{2}x\,dx=\tan x+C$$\int\csc^{2}x\,dx=-\cot x+C$
$\int\sec x\tan x\,dx=\sec x+C$$\int\csc x\cot x\,dx=-\csc x+C$
$\int\dfrac{dx}{1+x^{2}}=\arctan x+C$$\int\dfrac{dx}{\sqrt{1-x^{2}}}=\arcsin x+C$
$\int\dfrac{dx}{\sqrt{x^{2}+a}}=\ln\left|x+\sqrt{x^{2}+a}\right|+C$

② 常见凑微分表

凑微分凑微分
$dx=\dfrac1a\,d(ax+b)$$x\,dx=\dfrac12d(x^{2})$
$\dfrac{dx}{\sqrt x}=2\,d(\sqrt x)$$\dfrac{dx}{x^{2}}=-d\!\left(\dfrac1x\right)$
$x^{\mu-1}dx=\dfrac1\mu d(x^{\mu})$$\dfrac{dx}{x}=d(\ln|x|)$
$e^{x}dx=d(e^{x})$$\sin x\,dx=-d(\cos x)$；$\cos x\,dx=d(\sin x)$
$\sec^{2}x\,dx=d(\tan x)$；$\csc^{2}x\,dx=-d(\cot x)$$\sec x\tan x\,dx=d(\sec x)$；$\csc x\cot x\,dx=-d(\csc x)$
$\dfrac{dx}{1+x^{2}}=d(\arctan x)$$\dfrac{dx}{\sqrt{1-x^{2}}}=d(\arcsin x)$

万能型：$\displaystyle\int\dfrac{f'(x)}{f(x)}dx=\ln|f(x)|+C$（$\tan x$、$\frac{1}{x\ln x}$、$\frac{e^x}{e^x+2}$ 皆此型）。

③ 方法选择器（按长相找招）

长相招法
根式化分数指数后是幂和直接积分（化幂、加减一项）
$f(\square)\cdot\square'$ 结构第一换元（凑微分）；线性整体除系数
$\sqrt[n]{ax+b}$、双根号、分母高次 $x$第二换元（根式换元 / 最小公倍根 / 倒代换）
$\sqrt{a^{2}-x^{2}}$ / $\sqrt{x^{2}+a^{2}}$ / $\sqrt{x^{2}-a^{2}}$三角换元：$a\sin t$ / $a\tan t$ / $a\sec t$，画三角形回代
两类函数相乘（幂×三角/指数）分部积分："反对幂三指"排前者当 $u$
$\ln x$、$\arctan x$ 单独积分分部：$u=$ 它本身，$dv=dx$
$e^{ax}\sin bx$ 型分部两次循环移项（或引用⑧中 9、10 号）
假分式长除化"多项式 + 真分式"
真分式可分解 / 不可分解裂项待定系数 / 凑分母导数 + 配方 $\arctan$
三角：幂 / $1\pm\sin$ / 对称 / 线性比降幂 / 乘共轭齐次化 / 同除 $\cos^2$ 化切 / 一次项重组 / 万能公式兜底

④ 分部积分与经典结果

积分结果
$\int x\cos x\,dx$$x\sin x+\cos x+C$
$\int x\sin x\,dx$$-x\cos x+\sin x+C$
$\int xe^{x}dx$ / $\int x^{2}e^{x}dx$$(x-1)e^{x}+C$ / $(x^{2}-2x+2)e^{x}+C$
$\int\ln x\,dx$ / $\int\arctan x\,dx$$x\ln x-x+C$ / $x\arctan x-\frac12\ln(1+x^{2})+C$
$\int\tan x\,dx$ / $\int\cot x\,dx$$-\ln|\cos x|+C$ / $\ln|\sin x|+C$
$\int\sec x\,dx$ / $\int\csc x\,dx$$\ln|\sec x+\tan x|+C$ / $\ln|\csc x-\cot x|+C$

⑤ 三角降幂与万能公式

项目内容
降幂$\sin^{2}x=\dfrac{1-\cos2x}{2}$；$\cos^{2}x=\dfrac{1+\cos2x}{2}$
万能公式$t=\tan\dfrac x2$：$\sin x=\dfrac{2t}{1+t^{2}}$，$\cos x=\dfrac{1-t^{2}}{1+t^{2}}$，$dx=\dfrac{2\,dt}{1+t^{2}}$（算完回代！）
凑微分求 tan$\int\tan^{n}x\sec^{2}x\,dx=\int\tan^{n}x\,d(\tan x)$；$\int\tan x\sec^{2}x\,dx$ 类同

⑥ 复杂函数积分表（10 条）

#公式

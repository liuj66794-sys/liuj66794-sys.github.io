求导公式与求导法则速查表

📄 建议打印随身 第 3、4、5 单元通用（积分是它的逆运算） 来源：笔记《导数与微分》§二 · §五–§十一

① 基本求导公式（16 条必背）

类型公式
常数、幂$(C)'=0$；$(x^{\mu})'=\mu x^{\mu-1}$
指数$(e^{x})'=e^{x}$；$(a^{x})'=a^{x}\ln a$
对数$(\ln x)'=\dfrac1x$；$(\log_a x)'=\dfrac{1}{x\ln a}$
三角$(\sin x)'=\cos x$；$(\cos x)'=-\sin x$；$(\tan x)'=\sec^{2}x$；$(\cot x)'=-\csc^{2}x$
三角（续）$(\sec x)'=\sec x\tan x$；$(\csc x)'=-\csc x\cot x$
反三角$(\arcsin x)'=\dfrac{1}{\sqrt{1-x^{2}}}$；$(\arccos x)'=-\dfrac{1}{\sqrt{1-x^{2}}}$；$(\arctan x)'=\dfrac{1}{1+x^{2}}$；$(\operatorname{arccot}x)'=-\dfrac{1}{1+x^{2}}$

符号三查：cot/csc/arccos/arccot 带负号；arcsin 与 arccos、arctan 与 arccot 互为相反。

② 四则与链式

法则公式
加减、数乘$(u\pm v)'=u'\pm v'$；$(Cu)'=Cu'$
乘$(uv)'=u'v+uv'$
除$\left(\dfrac uv\right)'=\dfrac{u'v-uv'}{v^{2}}$（下导上不导在前）
链式$y=f[g(x)]$：$y'=f'[g(x)]\cdot g'(x)$（由外向内逐层乘）

③ 六类求导法

类型方法
分段函数分段点用定义（左右导数相等），区间内用公式
隐函数两边对 $x$ 求导，含 $y$ 项带 $y'$，解出 $y'$
参数方程$y'=\dfrac{dy/dt}{dx/dt}$；$y''=\dfrac{(y')'_t}{x'_t}$（再除一次！）
幂指 $u^{v}$化 $e^{v\ln u}$ 或两边取对数；最后乘回 $y$
反函数$\dfrac{dy}{dx}=\dfrac{1}{dx/dy}$
复杂乘除开方对数求导法：取 $\ln$ 化乘为加

④ 微分

内容公式
定义$dy=f'(x)\,dx$（可导 ⟺ 可微）
阶的比较$\lim\dfrac{dy}{\Delta x}=f'(x_0)$：为 0 高阶、为 1 等价、其他非零同阶不等价
常用凑微分$x\,dx=\frac12d(x^2)$；$\cos x\,dx=d(\sin x)$；$e^{x}dx=d(e^{x})$；$\dfrac{dx}{x}=d(\ln|x|)$；$\dfrac{dx}{1+x^{2}}=d(\arctan x)$

⑤ $n$ 阶导公式

函数$n$ 阶导
$e^{x}$ / $a^{x}$$e^{x}$ / $a^{x}\ln^{n}a$（复合入框：$(e^{2x})^{(n)}=2^{n}e^{2x}$）
$\sin x$ / $\cos x$$\sin\!\left(x+\frac{n\pi}{2}\right)$ / $\cos\!\left(x+\frac{n\pi}{2}\right)$
$\ln(1+x)$$(-1)^{n-1}\dfrac{(n-1)!}{(1+x)^{n}}$
$\dfrac{1}{1+x}$$(-1)^{n}\dfrac{n!}{(1+x)^{n+1}}$
$x^{n}$ 求 $m$ 阶$m<n$：$\dfrac{n!}{(n-m)!}x^{n-m}$；$m=n$：$n!$；$m>n$：$0$

归纳型（$xe^x\to(x+n)e^x$）：求前几阶 → 找规律 → 代阶数。

⑥ 切线 / 法线 / 中值定理

项目公式
切线 / 法线$y-y_0=f'(x_0)(x-x_0)$；$y-y_0=-\dfrac{1}{f'(x_0)}(x-x_0)$
罗尔连续 + 可导 + $f(a)=f(b)$ ⇒ $\exists\xi$：$f'(\xi)=0$
拉格朗日连续 + 可导 ⇒ $\exists\xi$：$f'(\xi)=\dfrac{f(b)-f(a)}{b-a}$
柯西$+g'\neq0$ ⇒ $\exists\xi$：$\dfrac{f'(\xi)}{g'(\xi)}=\dfrac{f(b)-f(a)}{g(b)-g(a)}$
费马引理可导的极值点必是驻点（$f'(x_0)=0$）

⑦ 单调 / 极值 / 最值 / 凹凸 / 拐点 / 曲率

项目要点
单调$f'\ge0$ 增、$f'\le0$ 减；四步：定义域 → $f'$ 零点与不可导点 → 分区间 → 查符号
极值判定一$f'$ 左正右负极大；左负右正极小（含不可导点，首选）
极值判定二$f''(x_0)<0$ 极大、$>0$ 极小、$=0$ 失效
闭区间最值比驻点 + 不可导点 + 端点的函数值
凹凸 / 拐点$f''>0$ 凹、$f''<0$ 凸；拐点 = 变号点全坐标 $(x_0,f(x_0))$，间断点变号不算
曲率$k=\dfrac{|f''|}{\left[1+(f')^{2}\right]^{3/2}}$；参数式与极坐标式见讲课 0025
证不等式设 $F=$ 右 $-$ 左 → $F$ 起点值 → $F'$ 定号
